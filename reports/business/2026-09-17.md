## 一、国内商业案例（国内新商业 / 非标 / 主理人 / 轻创业 / 社区 / 文旅商业）

### 1. 市井十洲城（泉州·东海中央活力区）｜福建首个滨海非标商业街区
- **概况**：泉州城建集团 × 印力集团联手，商业体量约 20 万㎡，整体五期递进、总投资近百亿；定位「泉州千年商港遗址上的活态文化生活中心」，9 月一期二期计划开业。
- **亮点**：以泉州传统街巷为灵感，用「街·巷·院·场·台」灵活布局取代传统笔直动线；六大业态组团＝国潮品牌旗舰＋一县一品＋非遗制造＋寻味泉州＋寻味海丝＋夜经济；绑定南音/木偶/讲古等非遗演绎与融合餐饮，打造闽南早市、烟火夜市、文化市集。
- **盈利逻辑**：文商旅复合——租金＋首店/非遗品牌扣点＋夜间市集活动票/摊费＋文旅客流转化；滨海群落建筑实现空间与海景无缝衔接，提升停留时长与复访。
- **可复制优势**：「遗址＋活态文化＋非标动线」组合，适合历史文化名城滨水/老城更新；印力运营背书降低招商风险。
- **风险与国内落地可行性**：投资体量百亿级、五期开发周期长，对二线城市消费力与文旅客流依赖高；三四线同类项目易因客流不足陷入「建成即冷场」。建议采用「核心组团先开、分期验证客流」的轻启动策略。
- 来源：赢商网/搜狐转载，2026-09；抓取 2026-09-17。

### 2. ThePool 池里（深圳宝安老城核心区）｜00 后主理人团队操盘的城市度假商业
- **概况**：前身为 2006 年开业的宝安新安香缤广场，改造后建面约 3.4 万㎡，总投资 1.5 亿元；由深圳 TOP1 汤泉品牌「汤崎·汤泉生活」的 00 后主理人团队操盘，定位城市度假商业综合体。
- **亮点**：老百货存量改造＋汤泉/度假体验植入，将「洗浴＋餐饮＋零售＋社交」打包成「城市微度假」目的地，与一街之隔的海雅缤纷城形成差异化。
- **盈利逻辑**：门票/会员（汤泉）+ 餐饮零售联营扣点 + 周末/夜间经济溢价；以体验刚需拉动低频到访为高频。
- **可复制优势**：存量商业「体验业态锚定」改造模板清晰，适合一二线老旧购物中心焕新。
- **风险与可行性**：重体验业态前期硬件投入与能耗高，回本周期长；主理人团队年轻化带来运营稳定性隐忧。国内同类「商业＋汤泉/浴场」在北方更成熟，华南可作差异化试点。
- 来源：搜狐，2026-09；抓取 2026-09-17。

### 3. 长春坊超级市集（长春核心区）｜东北首个非遗核心超级市集形态非标商业
- **概况**：商业体量约 8.5 万㎡，以非遗文化为核心、超级市集为形态，7 月 28 日启幕（原文称 2026-07-28）。五大板块＝东北最大室内非遗街区＋地域特色餐饮＋潮流零售＋休闲社交＋亲子互动；引入大量本土非遗、东北餐饮、主理人及特色首店。
- **亮点**：「非遗活化＋地域焕新＋社交聚合」三位一体，常态化非遗展演/主题市集/民俗展演，把地域文化转为商业价值。
- **盈利逻辑**：市集摊位/快闪租金 + 非遗体验付费 + 餐饮零售联营 + 节庆活动 IP 化运营。
- **可复制优势**：适合东北及北方城市「市井烟火气」存量改造，低门槛主理人/非遗摊位招商灵活。
- **风险与可行性**：东北人口流出与冬季客流波动是硬约束；需以「强内容运营 + 节庆高频」对冲淡季。来源：搜狐，2026-09；抓取 2026-09-17。

### 4. 长沙碧湘楚巷 + TX 长沙｜非标艺术街区 / 百联 TX 策展零售本土化
- **概况**：长沙碧湘楚巷——首个「非标商业」艺术街区，保留市级文保「天符宫」，构建「时间漫道」沉浸式游览体系，计划引入 40% 特色首店；TX 长沙——百联 TX 模式走出上海的首个本土化标杆，投资约 1.78 亿元改造老旧商场，以「策展+零售」打造「流动的文化片场」。
- **亮点**：文保活化 + 策展型零售，把空间变为「秀场」，消费变为「参与」。
- **盈利逻辑**：首店/策展品牌扣点 + 策展活动赞助 + 内容事件高频迭代带来的复访。
- **可复制优势**：TX 模式已验证于上海，长沙为二线城市策展零售复制样本，可对标成都 COSMO/重庆下浩里。
- **风险与可行性**：策展运营对团队内容能力要求极高，内容断更易失速；二线城市需平衡「网红化」与本地真实消费。来源：今日头条，2026-09；抓取 2026-09-17。

- **运营模式**：泉州城建集团（国资）拿地开发 + 印力集团运营；「街·巷·院·场·台」非标动线，非遗/国潮/海丝/夜经济五大组团，常态化非遗展演+主题市集运营。
- **收入方式**：商铺租金 + 首店/非遗品牌联营扣点 + 夜间市集摊位/活动费 + 文旅客流转化；客单价「待核实」，坪效「待核实」。
- **合作方式**：国资平台 × 专业商管（印力）联营/委托运营；品牌方以首店/非遗旗舰入驻，分成模式「待核实」。
- **存活信号**：一期二期 2026-09 开业（新开业）；依托世遗泉州文旅客流，声量处预热期；风险为百亿级五期开发周期长、二线城市消费力考验。

### 案例 B：ThePool 池里（深圳宝安·旧改城市度假）
- **运营模式**：00 后主理人团队（汤崎·汤泉生活）操盘；老百货 3.4 万㎡ 改造，汤泉/度假体验为锚，组合餐饮零售社交。
- **收入方式**：汤泉门票/会员 + 餐饮零售联营扣点 + 周末夜间溢价；客单价「待核实」，坪效「待核实」。
- **合作方式**：存量物业改造（原香缤广场），品牌/餐饮以联营扣点入驻；物业权属与分成「待核实」。
- **存活信号**：新开业（2026 年改造后入市）；汤泉母品牌深圳 TOP1 背书，但团队年轻化存运营稳定隐忧；华南「商业+汤泉」差异化可行。

### 案例 C：长春坊超级市集（长春·非遗核心超级市集）
- **运营模式**：8.5 万㎡ 超级市集形态，非遗核心 + 地域餐饮 + 主理人 + 特色首店；五大板块，常态化非遗展演/主题市集。
- **收入方式**：市集摊位/快闪租金 + 非遗体验付费 + 餐饮零售联营 + 节庆 IP 活动；客单价/坪效「待核实」。
- **合作方式**：非遗品牌/东北餐饮/主理人低门槛入驻（联营或短租）；具体分成「待核实」。
- **存活信号**：7/28 启幕（已运营约 7 周）；东北人口流出与冬季客流波动是硬约束，需强内容运营对冲淡季。

### 案例 D：西兴隆街（北京·运营前置首店集群）｜维持前期观察
- **运营模式**：16 座恢复式修建院落（朱小地等 7 位设计师领衔），建面约 1.46 万㎡；**运营前置**——设计阶段即介入运营团队，提前规划香氛/家居/精品咖啡等业态（沙城记忆×银匠兴隆北京首店、馥郁满铺华北首店、浴见华北首店、之禾&Carven PARIS 博物馆等）；预计 9 月底开街。
- **收入方式**：首店/主理人租金 + 文化商业联营；客单价/坪效「待核实」。
- **合作方式**：designers + 运营前置团队 + 品牌首店；国资/街区更新平台主导，品牌以首店形式入驻。
- **存活信号**：9 月底开街（临近）；「运营前置」降低招商错配风险，是老城更新可复制范式；风险为北京商品零售承压（上半年社零商品 -2.4%）下的体验业态真实转化。

> 每日追踪结论：本期新增非标/主理人典型案例 4 个（市井十洲城、ThePool 池里、长春坊超级市集、西兴隆街）。共同趋势＝「运营前置/内容运营 > 硬件装修」「存量改造 + 体验锚定」「地域文化 IP 化」。风险共性＝重内容运营能力、客流波动、二三线消费力考验。
