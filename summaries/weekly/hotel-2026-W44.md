## 三、出圈设计感 / 高热度特色酒店盘点

1. **上海斐乐酒店（运动品牌进酒店 · 出圈焦点）**——全球首家 FILA 运动时尚生活方式酒店，隶属凯悦尚选（JdV by Hyatt），落子上海安踏中心（青浦西虹桥），**108 间客房**（凯悦官网 / 中国日报网 / HOTELS Magazine 三源交叉核验）；斐乐悦动主题套房最高约 **¥2228/晚**。1911 意式地中海餐厅 + 蟠和闽粤餐厅 + 三层 PURE 健康运动空间（泳池 / 团体训练 / 瑜伽普拉提 / Re:set 恢复）。**出圈原因**：运动品牌首次以自有品牌直进酒店业、由国际集团软品牌承接运营，是"品牌体验试验田"与"建筑即内容"新范式（中国日报网 2026-10、新华报业网、HOTELS Magazine 2026 Q4 清单）。
2. **中卫·大漠梭梭度假酒店（双 11 宅度假标杆）**——背靠腾格里沙漠，住客获蚂蚁森林梭梭树植树证书；双 11 套餐累计成交额 **超 6000 万元**，证明"酒店即目的地、卖时间而非卖房间"的商业模式已在单体精品酒店跑通（江苏商报 / 网易 / 劲旅网，2026-10-28 至 29）。
3. **上海缤纷里希尔顿嘉悦里（乐园 + 生活方式）**——依托上海乐高乐园（首年接待破 200 万人次），节假日多次满房、亲子与商务多元并进（酒店圈儿 / 日报复盘）。
4. **北京北辰万豪侯爵（中轴叙事）**——从北京中轴线汲取灵感，671 间客房俯瞰城市或远眺西山，绑定双奥与国家会议中心二期会展客源，是"地标 + 会展"型城市旗舰（万豪旅享家）。

## 四、设计师酒店观察（建筑师 / 主理人作品）

- **悦榕庄「在地疗愈」范式**（广州九龙湖）：延续"独栋汤泉 + 景观框景"，弱化大堂仪式、强化客房私汤，"把自然放进客房"，适合康养长住（悦榕官方）。
- **万豪侯爵「城市策展」范式**（北京北辰）：以中轴线为叙事主轴，用空间序列替代装饰堆砌——"地标叙事比硬件堆料更具溢价"（万豪旅享家）。
- **SOM + KCA「东方静奢行宫」范式**（静奈·杭州）：SOM 合伙人 Michael Duncan 以"站立的西湖"塑北立面垂直湖面，室内由缔造迪拜帆船酒店的 KCA 创始人周娟操刀，六层 8000㎡"御西湖"连接水景园林与城市天际线（网易号·外滩设计酒店）。
- **国际设计天团密集落地**：如恩 Neri&Hu（天津柏典、景德镇英迪格）、王澍（松赞昆明林卡）、David Chipperfield（南京嘉佩乐）、Ole Scheeren（杭州瑰丽、三亚丽晶）、Bill Bensley（千岛湖瑞吉）、Joyce Wang（香港置地文华东方）集中在中国市场交付，"建筑即内容"的溢价与流量逻辑重塑高端竞争（外滩设计酒店 / 酒店圈儿）。
- **FILA × 凯悦尚选（软品牌试验田）**：FILA 意式运动传承 + 安踏业主建筑与主题装修 + 凯悦运营管理，"运动致美"融入全场景，运动品牌 IP 资产化新路径（中国日报网 / HOTELS Magazine）。
- **存量更新范式**：武汉丽怡（老旧楼宇改造）、广州西关全季 5.0（老城更新）代表"旧改 + 品牌"轻资产路径；上半年新开业中高端酒店改造换牌占比升至 **46%**（去年 34%），呼应降本增效周期。
- **流量逻辑**：抖音心动榜累计曝光 **超 103 亿次**、上榜商家销售额 +40%、核销订单 +60%；80% 用户因"特色主题和文化内容"心动，在地体验型酒店入住率高出 16%+、体验打包溢价 33%（读特 / 深圳晚报 / 信息时报）。
