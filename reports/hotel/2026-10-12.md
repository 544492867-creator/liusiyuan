## 二、民宿市场趋势（避暑旅居 / 设计感 / 在地感 → 节后降温与监管出清）

**双节"在地慢游"全面压倒"特种兵打卡"，但节后民宿端出现**显著降温与 K 型分化**，监管规范化加速出清。** 国庆实测与节后复盘显示，民宿并非全线下滑，而是"头部稀缺景观精品稳、中间同质化模板崩"的结构性出清：

- **途家**：连住 3 天及以上订单同比 **超五成**；"95 后 / 00 后"订单占比 **超 45%**；约 1/5 游客在两座及以上城市订民宿（多城串游）；国庆预订 TOP5 城市：青岛 / 北京 / 成都 / 重庆 / 南京（前序 + 本期维持）。
- **木鸟**：连住 7 天及以上订单同比 **+30%**；三线及以下城市日均订单 **+17%**；家庭游订单占比 **53%**（前序 + 本期维持）。
- **节后降温实证（今日头条 / 腾讯新闻，2026-10-08 至 10-10）**：大理全州 **10.32 万张民宿床位**，国庆期间平均入住率仅在 **50%–55%** 之间（近一半空置）；丽江五千多家民宿旺季入住率从往年七成多**跌到三成到四成**；莫干山曾动辄三千一晚的精品民宿国庆降到**八百出头**、订单仍不及预期；整租民宿均价较两年前**跌三成多**，热门旅游城市降幅更大。多位经营者反映预订高峰仅集中在 10.2–10.4 三天，5 号之后人流明显下滑。
- **K 型分化（迈点 / 媒体归纳）**：头部高端精品、带独家景观的特色民宿入住率仍稳定 **75% 以上**；真正承压的是占市场绝大多数的中端 / 大众民宿——普通民居改造、无特色、服务参差，入住率同比掉 **10–15pct**。"50 元 / 床位仍无人住"的极端案例在部分景区周边出现（云南、江苏、福建多地经营者自述），本质是供给增速远超游客增速 + 连锁酒店下沉挤压 + 年轻人"确定性消费"回流标准化住宿。
- **供给侧洗牌（行业观察，非官方网签）**：截至 2025 年底全国民宿相关企业 **38.3 万家**（企查查口径，腾讯新闻 2026-10-04）；2026 开年大量民宿经营者在社交平台宣称闭店或转行。存活样本仅两类——① 高端品质民宿（稀缺景观 + 专业设计 + 主理人 IP + 体验闭环）；② 低成本轻运营特色小屋。**中间"拼凑网红模板"层是 2026 闭店潮主力**。

**监管规范化成为 2026 产业升级核心抓手（本期重点更新）**：
- **四川雅安**：《雅安市民宿促进和管理若干规定》于 **2026-09-10 市人大通过、2026-09-24 省人大批准**，将于**明年 1 月正式施行**——据检索为**省内首部民宿专项法规**，从开办条件、安全标准到服务规范作明确规定，并统筹基础设施、公交接驳、信贷支持与文旅元素融入（大熊猫 / 蒙顶山茶 / 非遗）。
- **云南**：《云南省旅馆业治安管理实施细则》**自 2026-10-01 起施行**；文山州公安局 2026-09-15 公告明确，网约民宿 / 公寓等新业态住宿**须取得营业执照并向公安机关申领特种行业许可证**方可开业，10-01 起无证经营将依法处罚。
- **广东 / 多地**：珠海万山海洋开发试验区《民宿管理办法（试行）》（珠万管〔2026〕11 号）、江门《民宿管理暂行办法》（2026-05-09 施行，有效期至 2029-05-08）先后落地，明确场地、卫生、安全、退改与信用监管；广东江门、上海松江、福建厦门等多地发布民宿管理细则。
- **行业治理逻辑转变（北方网，2026-08-24）**：全国民宿正式建立"属地管理、部门联动、行业自律、社会监督"四维监管体系，文旅 / 公安 / 市场监管 / 卫健 / 消防 / 生态环境多部门协同，强化事中事后监管、房源备案台账、信用分级管理，对违规失信民宿实行限期整改、停业整顿、公示清退。

**趋势判断**：监管抬高准入门槛 + 连锁酒店下沉（汉庭 / 全季 / 亚朵等国庆预订同比近 +四成）双向挤压，民宿行业正从"颜值 / 流量竞争"转向"合规 / 品质 / 特色竞争"。短期看，节后淡季（W41）普通民宿空置率或进一步走高；中长期看，品牌化、连锁化、特色化头部玩家将做大，中间层持续出清。

## 四、出圈设计感 / 高热度特色酒店

## 七、当日趋势点评

1. **节后 W41 淡季空窗已开启，但双节"量强价弱"定调全年节奏**。截至 10-12 抓取，W41（10.5–10.11）周度数据尚未发布；以最新 W40（STR 口径 RevPAR −10.5%）与国庆日度均值（国信口径 RevPAR −3.3%、ADR −2.9%）为参照，旺季靠出租率硬撑、价格普遍 −2%~−7%，"旺丁不旺财"特征明确，并在节后进一步走弱。
2. **量价背离是本期最稳固的结论**。STR W40 RevPAR −10.5%、酒店之家 W40 RevPAR −2.2%、国信国庆日度 RevPAR −3.3% 三套口径方向一致；W40 RevPAR 195.3 元较 8.18 基线 215.5 元 **−9.4%**、OCC 66.8% 较基线 **−7.0pct**，暑期峰值完全退潮。
3. **档次与线级结构分化加深**。STR W40 奢华 −11.5% / 中高端 −9.5% 跌幅最深；国信国庆日度豪华型 **−11.9%**、高档 −8.4%，而一线 RevPAR **基本持平**、高档型在酒店之家周度口径中 **+0.9%**——高奢价格护城河被系统性削弱，一线城市与稀缺资源型供给相对抗跌。
4. **供给过剩 vs 需求温和修复是核心矛盾**。OTA 酒店数同比 +25.1% 至 105.2 万家、客房 +5.4% 至 2357.7 万间，Q4 在秋假政策 + 商旅修复下预计 RevPAR 同比"持平为主"（中金 / 国信 / 投研社一致预期），难回 8 月暑期峰值。
5. **民宿两极分化进入出清加速 + 监管规范化共振期**。大理 10.32 万床位仅 50%–55% 入住、丽江跌至三成到四成、莫干山降至八百出头，与头部精品 75%+ 稳居形成 K 型；同期雅安首部民宿专项法规（9-24 批准、明年 1 月施行）、云南《旅馆业治安管理实施细则》（10-01 施行）、珠海 / 江门细则落地，抬高准入门槛——"合规 + 品质 + 特色"取代"颜值 + 流量"成为生存线。
6. **集团分化：亚朵靠零售突围，华住靠规模与加盟，锦江 / 首旅靠管控增效**。亚朵第三季度（财经中国披露）营收 26.28 亿元（+38.4%）、调整后净利 4.88 亿元（+27%）、零售 9.9 亿元（+75.5%），双十一床上用品稳居头部；华住 Q2 通过 3 年 25 亿美元股东回报计划、国庆 970 万+ 接待印证规模韧性；锦江 2026 中报营收 68.01 亿（+4.21%）、归母净利 5.69 亿，完成超 380 家存量门店升级；首旅 H1 营收约 35.8 亿（−2.22%）、归母净利 4.41 亿（+10.98%）。存量经营承压（华住中国成熟酒店同店 RevPAR 下滑）仍是行业共性挑战。
7. **内容即入口彻底兑现，但"位置 > 价格、场景 > 位置"逻辑未变**。抖音酒旅视频 3.8 亿个、播放超 4025 亿次（前序腾讯新闻转载）；在稀缺景观（大理头部、舟山滨海）、山景（本溪 +3 倍、连云港满房）、场景（万岁山 +近三成）三类目的地酒店与民宿仍能"涨得动"，标准商务与县城模板型供给则无力定价。
