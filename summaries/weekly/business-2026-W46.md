## 四、趋势变化（判断性结论）

1. **双十一从「GMV 竞赛」彻底转向「直价 + AI + 服务」，且口径信任度成核心议题**：星图 11-12 定格全网 17764 亿 +4.8%、即时零售 891 亿 +33% 成唯一亮点；但五个机构口径（1.21 万亿~1.77 万亿）并存、退货率 15%~80% 分歧巨大，反映「大促存量深耕 + 数据口径失焦」并存。规则做减法（满退场、立减首屏），AI 站到链路中央（79.4% 先问 AI、43.7% 影响力首超广告、Token 成商品），「算力即商品、AI 即入口」成新基础设施。
2. **万达「规模让位于质量」信号明确，轻资产 + 存量改造 + 生态场景成新引擎**：全年 13 座创十年最低（2016 峰值 56），但玉林玉东以「159 品牌 + 40+ 首店 + 1200 株绿植 + 24 小时金街 + 可计量固碳 42 吨」把「生态场景」做成差异化货币；临汾尧都（晋菜街区）、河源东源（恐龙盲盒 + 客家空中花园）以在地 IP 替代标准盒子。
3. **龙湖「天街矩阵」把单点招商风险摊薄成城市级网络效应**：长沙开福（12 万㎡ / 78 首店 / 45 万客群）与成都驿都（14 万㎡ / 近 300 品牌 / TOD）11-13 同开，叠加长沙新姚、杭州滨康接力；以「高首店比 + 亲子高频 + 定制化店型 + 会员中台」做复购型区域商场，是存量时代最稳扩张姿势。
4. **消费基础设施 REITs 进入「多单并行、梯度盘活」常态化**：华润（南通 / 临沂）、大悦城（天津，估值 63.02 亿）、吾悦（15.53 亿）、凯德（分派率 5.22%/5.25%）、保利（5.99%）、西安高科多单集中落地，为持有型商业提供「募投产建管退」估值锚与退出通道，低利率下成保险 / 年金配置核心。
5. **泰国「IP × 节庆 × 文旅综合体」密集兑现且升维**：CentralWorld 圣诞 IP（4000㎡+、每日人工降雪 4 次、TAT 集章扭蛋）与 One Bangkok 内容年轮（两周年收官转 Onederous Christmas 八大装置）把「免费公共景观」做成最强引流；Pokémon Center BANGKOK（海外最大、30 周年、泰国文化限定）再落重磅锚店；曼谷被机构列为全球奢侈品开店第 4。
6. **日本「IP 集群 + 站城一体 + 抽选控流」三线并发且向关西集中**：涩谷 PARCO 11 月三店（sanrio house 11-13 / WILDSIDE + GUNDAM BASE 11-20）以高频 IP 锚定国际游客；大阪 LUCUA SOUTH 角色楼层 11-24 以「28 间同步开、32 角色品牌、53 间全面后」把梅田升级为关西二次元总枢纽；皇居 Ote Rest House 是文博公共空间民企运营首例——共同指向「存量空间的体验化改造 + 内容持续供给」。

- **可借鉴点**：① 标准化产品线快速复制 + 区域独家品牌做稀缺；② 多天街接力摊薄营销与招商成本、共享会员中台；③ 「公园 + 乐园 + MALL」家庭目的地适配人口导入期。**风险**：日常坪效比开业客流更说明问题；开业后首周真实客流 / 销售——**数据源不可用（以龙湖战报为准）**。
