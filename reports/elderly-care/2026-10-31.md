## 一、政策动态（国家 / 地方扶持政策、产业新规）

> 本期主线：国家层面「价格机制定型 + 联合检查常态化 + 长护险全国建制冲刺 + 银发消费促动 + 康复辅具三年行动 + 第六次抽样调查推进」六线并进；地方长护险居民征缴进入密集落地窗口（太原 / 湖北 / 安徽 / 上饶 / 重庆 / 宿迁 / 宜春 / 淮安 / 吉安 / 涟水），青岛「敬老月收官 + 银发消费季 + 一类事」服务集成持续释放；适老化改造、以旧换新补贴向适老硬件倾斜。

### 1. 普惠养老服务价格机制文件持续落地（国家层面核心制度增量）
- **文件**：国家发展改革委、民政部、国家卫生健康委《关于进一步完善价格形成机制 推动普惠养老服务提质扩面的指导意见》（**发改价格〔2026〕1476号**），2026-10-12 印发，央视网 10-17 作专题解读，中国政府网 10-16 全文公开。
- **核心内容**：首次在国家层面将养老机构分为三类并差异化定价——兜底保障型（特困 / 经济困难失能老人公办机构，基本服务费政府指导价、特困免费收住）、普惠支持型（公建公营 / 公建民营社会办及获场地减免或建设运营补贴的社会办机构，基本服务费政府指导价或参考区间，具体范围由省级民政制定认定办法、地级及以上民政认定并发布名单）、完全市场型（市场调节价、鼓励优质优价）。建立目录清单管理（所有收费进清单、清单之外一律不得收费）、收费动态评估（周期 ≤3 年），总体按「补偿成本、合理盈利」原则。
- **配套资金**：发挥中央预算内投资、超长期特别国债、地方政府专项债券带动作用；用水用电用气用热按居民生活类价格执行；用好地方留成彩票公益金强化养老护理员队伍。
- 来源：https://www.gov.cn/zhengce/zhengceku/202610/content_7083441.htm ；https://www.mca.gov.cn/n152/n166/c1662004999980014097/content.html ；https://www.ndrc.gov.cn/xwdt/tzgg/202610/t20261016_1408180.html

### 2. 养老机构常态化联合检查机制意见（七部门「一张表」）
- 民政部会同自然资源部、住建部、水利部、应急管理部、市场监管总局、国家消防救援局印发《关于健全养老机构常态化联合检查机制的意见》。聚焦建筑、燃气、用电、特种设备、消防、食品、防汛，「一张表」联合检查、进一次门一表通查；县级每年至少 1 次联合检查；「一院一策」整改、风险等级动态录入全国养老服务信息系统。
- 来源：界面新闻 / AgeClub 行业热点 2026-10-19 条目

### 3. 长护险全国建制加速（社保「第六险」）—— 最新官方口径（2026-09-04 国新办发布会）
- 国家医保局副局长王文君 2026-09-04 披露：截至 2026-09，**22 个省份**印发省级实施方案，**建制统筹地区 121 个**（年底拓展至 **247 个**），参保 **超 3.2 亿**，基金累计支出 **1142 亿元**，为 **超 460 万**失能人员提供护理服务；定点长护机构 **1.3 万家**，护理服务人员约 **40 万**，培养长期照护师 **超 7 万**（另口径：截至 2026-07 全国统一长期照护师持证人数突破 **5 万**）。拉动社会资本近 **700 亿元**。

### 4. 地方长护险密集落地（居民征缴全面启动 + 本期新增太原 / 湖北 / 安徽 / 上饶 / 重庆口径）
- **太原（新华网 2026-10-30）**：太原市政府办公室 2026-09-23 印发《太原市长期护理保险制度实施细则》。2026-10 结合城乡居民医保同步启动未就业人员长护险保费征缴，2026-12 启动就业人员征缴，**2027-01-01 起分批兑现待遇**；覆盖全体基本医保参保人员（职工、退休、灵活就业、城乡未就业居民）。费率 0.3%：单位职工单位个人各 0.15%（平移职工医保单位 0.15% 费率、不增加企业负担），退休 0.15%；城乡未就业居民个人与财政 1∶1、首年减半、5 年过渡至 0.3%；18 周岁以下随抚养人纳入。待遇无起付线、差异化支付：就业人员居家 / 社区 / 机构护理基金支付 **75% / 70% / 65%**，年度最高 **16920 元**；未就业人员对应 **55% / 50% / 45%**，年度最高 **12240 元**。太原为「国家长期护理保险制度建设重点联系城市」。
- **湖北（鄂政办发〔2026〕21号，10-27/28 解读）**：采取「先职工、后居民」，用 3 年基本建立；2026 年有条件市州启动单位职工 / 退休 / 灵活就业，2027 年纳入未就业城乡居民，**2028 年底**统筹城乡制度基本确立。费率 0.3%：单位职工单位个人各 0.15%，退休 0.15%，未就业居民个人财政 1∶1 左右。

- **重庆（居民 2026 年 Q4 启动参保）**：全市 60 岁及以上常住人口 **835.06 万**（占 26.2%，西部第一）。居民长护险 2026 Q4 启动、与居民医保同步筹资，**2027 年起享待遇**；2027 筹资费率减半按 0.15%、5 年过渡至 0.3%，2027 年筹资约 **62 元 / 人·年**（个人约 31 元）。截至上半年定点护理机构 **768 家**、专职护理 **1.75 万**人；长期照护师培训机构 **36 个**、**8334 人**持证；失能评估机构 148 家、评估人员 6432；成渝评估结论互认 **1168 人次**。试点以来参保超 **800 万**、累计 **10.51 万**失能人员享待遇、减负 **20.91 亿元**。

- **巴南（重庆，人民网 10-17）**：截至 2026-09 全区基本医保参保 **96.81 万**，职工群体长护参保全覆盖；累计 **1.2 万+**失能人员享待遇，定点护理机构 **42 家**、专职护理员千余人，在享 **4500 多人**。

## 五、全球养老标杆案例观察：**英国「Extra Care Housing / 集成退休社区（IRC）」—— 终身住宅 + 在地照护**

> 轮换说明：上期（10-30）跟踪荷兰 De Hogeweyk 失智长者村；上上期（10-29）日本地域包括照护系统；上上期（10-28）新加坡乐龄 Age Well SG；再前（10-27）德国多代屋。本期切换至**英国「Extra Care Housing（额外照护住房）/ 集成退休社区 Integrated Retirement Communities（IRC）」**，呼应国内「居家社区机构协调、原居安老、社区嵌入式、物业 + 养老」主线，以及青岛「五床联动 + 社区融合」方向。英国作为全球「原居安老（Ageing in Place）」与「住房即照护（Housing with Care）」模式的发源地之一，对国内社区嵌入式养老、老旧小区适老化、物业 + 养老有直接借鉴价值。

### 1. 概念与定位
- Extra Care Housing 又称「very sheltered housing（超 sheltered 住房）」「housing with care（带照护的住房）」「assisted living（辅助生活）」，在英国被视为「care home（护理院）的替代选项」。核心是：长者拥有**自己的前门、独立厨房客厅**，拥有房屋法律占有权；**24 小时照护服务按需可用**；目标是「home for life（终身之家）」。
- 形态多元：新建退休村（retirement villages）、改造后的 sheltered housing、公寓楼、平房社区等；可租、可买、可共有产权。
- 来源：https://www.bexley.gov.uk/sites/default/files/2021-11/Ageing-Well-Strategy-2018.pdf ；https://www2.oxfordshire.gov.uk/cms/sites/default/files/folders/documents/socialandhealthcare/housing/extracarehousing/echnewleafletformatted.pdf

### 2. 运营特征：独立生活 + 社区融合 + 慈善底色
- **独立与隐私优先**：resident「living at home – not in a home」，自己决定谁来、控制财务；鼓励夫妻 / 朋友同住；可参与或不参与社交活动。公共设施含餐厅、健身房、爱好室、IT 室、图书馆、村民大厅等。
- **混合权属（mixed tenure）典范——ExtraCare Charitable Trust**：英国领先非营利退休村开发商，刻意设计为「outright homeowners（全产权业主）/ shared ownership（共有产权）/ social renters（社会租赁）/ private renters（私人租赁）」混合社区，避免「排他性、单一化」，形成真实平衡的社区（residents 称其「more grounded、more socially connected」）。
- **buy-back 承诺（回购保证）**：居民购买 ExtraCare 房产后，慈善机构承诺按「原价减去少量明确成本」回购，消除「卖不掉、套牢」的担忧，给居民与家属确定性。
- **福利收益团队（Welfare Benefits team）**：专员帮潜在 / 现有居民申领应得福利（如 Attendance Allowance），有居民因此每周多 **168 英镑**可支配收入，「从以为负担不起到 affordable」。
- 来源：https://www.extracare.org.uk/news/why-extracare/ ；https://www.extracare.org.uk/what-is-a-retirement-village

### 3. 成效证据（学术研究 + 议会证据）
- **英国议会 ILC-UK 证据（HOP0079）**：基于三家供应商纵向数据（部分记录超 15 年）——Extra care 是「home for life」；入住者进入机构照料的概率**低于**社区中接受居家照护者；约 **24%** 带照护需求入住者 5 年后能力反而改善；住院过夜概率低于匹配社区样本（节省可达 **£512 / 人**）；跌倒率 **31%** vs 社区 **49%**。
- **Aston & Lancaster 大学与 ExtraCare 研究**：居民「从不或几乎不孤独」占 **86.5%**；焦虑症状降 **23%**、抑郁症状降 **14.8%**；运动量增加 **75%**；自传式记忆 +**24%**、记忆回忆 +**17%**。仅约 **20%** ExtraCare 居民实际在接受照护（独立生活导向）。
- **ARCO（集成退休社区运营商协会）愿景**：到 **2030 年**在 IRC 中容纳 **25 万**老年人——反映英国将「住房 + 照护 + 社区」作为应对老龄化的规模化方案。
- 来源：https://committees.parliament.uk/writtenevidence/79370/html/ ；https://www.extracare.org.uk/what-is-a-retirement-village

### 4. 镜鉴与难点
- **可借鉴**：①「原居安老 + 终身住宅」理念，与我国社区嵌入式、老旧小区适老化、物业 + 养老方向一致；②「混合权属 + 回购保证」破解「买不起 / 卖不掉」的可负担性难题，对国内「存房养老、以房养老、康养社区流转」有启发；③「住房即照护」——把照护服务嵌入日常居住而非集中机构，降低机构化；④ 公共设施对社区开放、成为区域服务 hub，呼应国内「一老一小」「物业 + 养老」融合。
- **难点 / 不可照搬**：① 英国高度依赖地方当局（local authority）法定规划与财政补贴，国内属地财政差异大；② 混合权属与共有产权依赖成熟住房金融体系；③ 我国「9073」格局下机构与社区边界、产权与租赁关系不同，直接复制退休村模式难度高；④ 照护人员配比、质量监管成本仍需本土化。
- 来源综合：https://committees.parliament.uk/writtenevidence/79370/html/ ；https://www.extracare.org.uk/what-is-a-retirement-village ；https://www.bexley.gov.uk/sites/default/files/2021-11/Ageing-Well-Strategy-2018.pdf

### 5. 本土化启示
- 对应国内「社区嵌入式养老机构 + 家庭养老床位 + 物业 + 养老 + 五床联动」组合：学习英国「住房即照护、独立优先、社区融合、可负担保障」内核，以「小区闲置资源改微型养老院 + 上门照护 + 适老化租赁」替代重型机构；探索「共有产权 / 回购型」康养社区流转机制，降低居民长期锁定风险；把公共设施（餐厅、活动室、康复空间）向社区开放，形成「一老一小」服务 hub。
- 来源综合：https://www.extracare.org.uk/news/why-extracare/

## 八、青岛康养地产政策专项（第 49 期）

> 基线（2026-07-23 发布，全国首个城市级康养地产系统性支持政策「11 条」）：健康服务中心「计容不计价」、出让款分期（最迟 1 年、付 50% 承诺 6 个月开工可进场）、「正负零」预售、「商改住」转型（自持 ≥10 年）、再贷款 1.25% / 最长 3 年、保险资金 REITs 等。本期追踪新动态。

### 1. 政策原文摘要（本期主线：从「供地优惠」转向「服务集成 + 消费促进 + 金融赋能」深化收官）
- **来青旅居康养「一类事」集成化改革（2026-10-10 发布）**：市行政审批局联合文旅 / 民政 / 公安 / 卫健 / 医保等 **22 部门**，围绕「食住行、游学乐、医康养」三场景，首批归集服务事项 **105 项**，「三个一」架构（一张清单聚需求 / 一套阵地就近办 / 一个矩阵广知晓）；选取崂山 / 西海岸 / 胶州试点，2026 年底前建不少于 3 处标准化样板站点（旅居服务微站）。
- **2026-10-14 青岛「敬老月」暨银发消费季**（民政局 / 商务局 / 文旅局 / 人行青岛市分行联合）：活动 10 月持续至 12 月（敬老月 10-01 至 10-31，征集 **48 项**特色活动），贯通「吃住行医康养游学乐」全消费场景。**新增亮点（本期）：指导 45 家养老机构推出「银龄试住周」**，通过低价试住、免费短期体验让老人实地了解服务环境。惠老购物端——全省率先新增 **8 类**地方自主补贴品类（助行外骨骼机器人、助听器等适老产品享 **15%** 补贴）；市级财政投放 **5000 万元**线上消费券（京东 / 抖音 / 淘天三大平台）。文旅端——依托「一张票根游青岛」小程序联动 **900 余家**合作商户；统筹推出 **8 款**康养旅居产品、**10 条**银发旅居康养精品线路（含「八大关颐居」「藏马山森氧疗愈」「即墨温泉疗养」及温泉疗愈·海洋暖养等 10 条线路）。
- **三年行动方案**（2025—2027，13 部门）：编制《青岛市康养旅居保障清单》《青岛市康养旅居地图》；组建康养旅居产业共同体（20 余家企业）；联动文旅打造 **18 个**旅居康养产品；与 20 余城市达成合作。
- **健康养老产业高质量发展行动方案**（20 部门，2026-02-03）：持续推进「五床联动」；到 2027 年培育 **10 个以上**健康养老服务品牌；支持智慧养老院、社区「虚拟养老院」、物业 + 养老、家政养老。

### 2. 核心条款解读
- 本期无新市级康养地产**土地 / 财税**专项文件印发；政策重心由「开发端优惠」（11 条基线）进一步转向「服务端集成 + 消费端促进 + 金融端赋能」（一类事 105 项 + 文旅 47 项 + 银发消费季 5000 万券 + 8 类 15% 补贴 + 45 家机构「银龄试住周」+ 全龄友好 + 旅居产品供给 + 140.3 亿产业贷款）。

### 3. 影响评估
- **对青岛本地项目**：泰康之家·海琴府、君凯养老等高品质机构落地；「五床联动」打通医养，降低机构医疗配套成本、提升入住信心；20 个健康养老品牌目标牵引供给提质；银发消费季 5000 万消费券 + 8 类补贴直接拉动适老产品本地消费；140.3 亿健康与养老产业贷款降低机构融资成本（利率 2.68%）；45 家机构「银龄试住周」降低决策门槛、转化潜在客群。

- **落地挑战**：105 项 + 47 项 + 8 类补贴从清单到「门口办 / 指尖核销」需三级阵地（政务中心专区 + 景区 / 机构微站 + 流动队）真正铺开；跨部门数据打通与「政策明白人」培训是关键瓶颈。
