## 二、民宿市场趋势（避暑旅居 / 设计感 / 在地感 → 节后错峰降价与监管加码）

**双节「在地慢游」退潮后，节后错峰窗口使民宿成为「降价最狠」的住宿品类——部分目的地近乎对折；K 型分化 +「床车分流」+「连锁下沉替代」三重新变量延续；本期监管侧除省级条例（湖南）、县域细则（云龙）、网约房公告（文山）外，新增人民日报·金台视线《住宅楼里办民宿，该怎么管》（2026-10-12）以读者来信 + 张力点评直击「住改商」执法落地难，山东《网约房治安管理规定（试行）》、浙江《民宿范围和条件指导意见》从治安 + 消防维度补细化。** 错峰游报道（封面新闻 / 川观新闻 2026-10-14）明确点出：景区周边民宿、度假酒店价格弹性最大，部分目的地住宿花费最高可较国庆省下 60%，不少热门民宿价格近乎打「对折」——既是普通民宿出清压力延续，也是错峰客群「捡漏」红利。

- **错峰降价实证（核心）**：10.9 后全国热门旅游城市酒店均价较国庆降超三成，**民宿 / 度假酒店弹性最大、部分省 60%**、不少热门民宿近乎对折（封面新闻 / 川观新闻 / 网易 / 金台资讯 2026-10-14 至 16，综合去哪儿 / 同程数据）；新疆阿勒泰、西藏日喀则中高档酒店均价低至 300 元，四川甘孜豪华型 10 月底仍有 200 余元房源；国庆期间动辄千元以上的景区周边民宿，节后回落至 500 元以内。
- **「连锁替代」硬证据（延续）**：国庆汉庭 / 全季 / 亚朵等连锁预订同比涨快四成且满房（腾讯新闻 / 今日头条 2026-10-08）；错峰期连锁凭借标准化 + 会员体系继续吸走价格敏感客群，民宿中间层承压；华住会 App 上线「旅居」频道切入平价月租（最低 1500 元起），进一步瓜分低标准化租房市场。
- **「暑期背离」硬证据（延续）**：2026 暑期国内出游 **11.2 亿人次、+32.7%**（网易 / 腾讯新闻 2026-10），但民宿订单不升反降、均价近乎砍半；热门景区周边中档民宿想保本月均入住率需稳在七成以上，今年很多店连五成都够不着。
- **K 型分化（延续）**：头部高端精品、带独家景观特色民宿入住率仍稳定 **75% 以上**；承压的是占绝大多数的中端 / 大众民宿，入住率同比掉 **10–15pct**；「50 元 / 床位仍无人住」极端案例在云南、江苏、福建、广西多地出现。
- **供给侧洗牌（非官方网签，沿袭 + 中国饭店协会新增）**：中国饭店协会《2026 中国酒店业发展报告》全国酒店客房总数约 **1873.6 万间**，供给进入相对饱和；截至 **2025 年末全国民宿 38.3 万家**（与 10-17 报告「2026 年 5 月 40.3 万家」为不同统计时点，并列标注）；**中国旅游协会 2025-10 全国民宿平均入住率 36%、均价 367 元（较 2024 年 489 元降约 30%）**；2025 年新注册约 **8.6 万家**、注销 / 吊销约 **2.9 万家**。
- **「床车分流」（延续）**：自驾游客睡在新能源车里（座椅放平 + 驻车空调），「床车自驾游」话题阅读量**破 1.1 亿**，甘肃高速服务区集中过夜上百辆——以「充一次电十几块」替代千元住宿。

**监管规范化纵深（本期：从原则倡导走向「准入 + 消防 + 治安 + 平台责任」全链条，并直面「住改商」执法落地难）**：
- **《湖南省民宿条例》——全国首部以民宿为主要规范内容的省级地方性法规（多源深化，延续）**：2026-09-23 省人大常委会通过，自 **2027-01-01 施行**（湖南人大网公告第 90 号；湖南省人民政府 2026-09-25 发布会）。人民日报·金台视线《住宅楼里办民宿，该怎么管》（2026-10-12 第 07 版）以读者来信 + 西南政法大学张力点评，指《条例》「推动从原则性规范走向准入、经营、平台和部门协同的全链条治理」，但「并非完整的前置备案制度，需细化认定办法、消防标准、审查材料和平台责任边界」；中国消费者报《守护消费者安心住》（湖南省市场监督管理局转载，2026-10-12）逐条解读：明码标价、禁强制搭售、仅**公共区域**可装监控、消防不达标须改造、禁地质灾害高风险区 / 违法建筑；核心红线：城镇住宅小区**四层以上禁开、四层以下须利害关系业主一致同意**；OTA 须实名核验营业执照 + 特种行业许可证。

- **「住改商」执法落地难（本期新增，金台视线核心议题）**：人民日报·金台视线汇集山西晋城、安徽合肥、陕西西安、江苏南京、广西桂林、上海黄浦等多地读者来信——住宅楼内无证民宿 / 网约房深夜喧哗、违规隔断（一套改 4–10 间、凿通防火隔墙）、电气火灾风险高，但基层因「上位法规细化不足、执法边界不清、民宿 / 网约房概念模糊、文旅部门无审批抓手」多停留在约谈劝导；西南政法大学张力建议**建立民宿前置登记备案制度**——开业前须提交有利害关系业主同意证明、消防合格证明、治安管理责任书，未备案即属非法经营由主管部门直接查处，并压实 OTA 房源前置审核主体责任（拒绝无备案房源上架）。

**趋势判断**：省级条例（湖南）+ 县域消防细则（云龙）+ 网约房治安公告（文山）+ 山东 / 浙江落地文件 + 金台视线「住改商」议题，标志民宿监管从「原则倡导」迈入「准入 + 消防 + 治安 + 平台责任」全链条，并正面回应「执法落地难」。叠加错峰期价格近乎对折、连锁下沉替代、床车自驾分流、「暑期 11.2 亿人次却订单背离」硬证据，民宿正加速从「颜值 / 流量竞争」转向「合规 / 品质 / 特色竞争」。短期 W42 普通民宿空置率或进一步走高；中长期品牌化、连锁化、特色化头部做大，中间层持续出清。
