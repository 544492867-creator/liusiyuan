## 四、趋势变化（判断性结论）

1. **消费结构 K 型分化固化**：总量平（商品零售 +1.0%）、结构热（服务 +5.0%、线上 +4.4%、县域 / 乡村 +2.3%）。商业增量集中在「体验、效率、确定性」三条线——非标文旅街区、会员业态近场化、高端确定性零售。
2. **非标竞争回归「内容持续供给能力」**：楚宝天地 / 古北妙街 / 蓉港荟 / 栖栖里 / 环場 / A.F.A / 日本 MICCA 等跨越「重—中—轻」多档，共性结论是「把空间让给日常与内容，而非让给货架」；但「周末人山人海、工作日凋零」「好看不赚钱」仍是核心考题。
3. **会员业态近场化 + 分层加密**：山姆长三角「一城三店 / 二店」、麦德龙临沂旗舰 + 前置仓、fudi 进社区、荟品仓城市奥莱、Costco 审慎西南首店——远郊目的地 → 近场社区 + 城市奥莱 + 前置仓的边界被重写。
4. **东京 / 曼谷存量提质 + 轻量非标并行**：池袋 PARCO、Longchamp / Loro Piana 表参道建筑即媒介旗舰、西武広島化妆品楼层体验重构、新綱島 MICCA 史迹再生——日本以「小体量、在地、低资本」对抗百货承压；泰国以 Central 生态平台 + One Bangkok 综合体规模制胜。
5. **双11 从「价格战」转向「服务战 + AI 战」**：家洛定调「不可能回五折」，国补 + 服务履约（京东服务 +130%）+ AI 决策 + Token 品类（+450%）成为新增量信号。
6. **地产金融化 + 国资接盘并行**：华润「百 Mall + 多层次 REITs + Pre-REITs 二期」成型；瑞安 / 新世界 / 上海实业资产腾挪，PAG / 博枫 / 星展围猎中国商业资产。

## 五、优质案例深读

### 案例一 · 三亚中免太古里（国内 · 度假型高端零售范式）
- **模式**：太古 × 中免 50:50 合资，作为三亚国际免税城三期，与一、二期无缝连接形成「免税 + 有税」互补共生；开放式低密度街区 + 疍家渔村 / 古盐田文化 + 古树保护。
- **设计**：「水天一线」滨水街区，17 栋独栋、纯商业建面约 23.1 万㎡；LV 5 号楼四层独栋（3,286㎡）、Dior 两层独栋（2,179㎡）等重奢落位。
- **客群**：海棠湾度假客流 + 高端旅游零售 + 康养客群；同湾丽晶 / 英迪格双品牌酒店（2027 竣工）形成「住宿—零售」闭环。
- **可借鉴点**：① 度假型零售把「在地文化」做成空间主轴而非装饰；② 免税与有税双引擎对冲周期；③ 重奢以独栋旗舰锁定稀缺供给。**风险**：分阶段开放节奏与首期品牌最终兑现仍「数据源不可用（以官方公告为准）」，且华润调规、东百入局、奢侈品牌系统性收缩使海棠湾供给结构生变。

### 案例二 · 新綱島 MICCA（日本 · 轻量非标再生范式）
- **模式**：东急推进、新綱島站前，由横滨市认定历史建筑「池谷家住宅主屋（OMOYA）」+ 新建木造商业「HANARE 北 / 南」三栋组成；21 家店（烘焙餐酒馆、串烧、洋食、意面、精酿汉堡等社区日常餐饮），11-3 MICCA 祭。
- **设计**：史迹活化 + 木造商业，敷地约 7,757㎡（OMOYA 317㎡ + HANARE 南 1,394㎡ + 北 1,209㎡），低资本、在地、社区日常。
- **客群**：横滨新綱島站通勤 / 日常 + 游客。
- **可借鉴点**：与 Rincon 千駄ヶ谷（翻新 office + 木造 shop 栋）、そよらつくば（AEON 社区据点）共同验证「历史 / 木造建筑 + 社区消费」的小型非标再生——以极低成本把存量空间转化为日常内容场，对国内城市更新「重投入、弱内容」是一剂对照。**风险**：开业后真实客流与坪效「数据源不可用（以运营方披露为准）」。
