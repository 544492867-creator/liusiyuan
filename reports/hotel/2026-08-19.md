## 一、全国酒店市场趋势（价格 / 客群 / 结构性分化）

**1. 头部集团 Q2 验证「量价韧性」，但 OCC 微降折射供给放量**
- 华住集团 8/17 发布 2026 Q2 财报：华住中国 RevPAR **238 元（同比 +1.1%）**、入住率 **OCC 79.8%（同比 -1.2pp）**、ADR **298 元（同比 +2.6%，连续四个季度正增长）**；全球在营酒店 **13,539 家**、客房 **133.5 万间**，Q2 新开业 **498 家**、净增 **322 家**。（来源：华住 2026 Q2 业绩公告 / 证券时报 / 上海证券报 2026-08-17）
- 较基线对照：华住个体 OCC 79.8% 高于 8/18 基线大盘 73.8%、ADR 298 高于 292、RevPAR 238 高于 215.5——**头部集团靠产品升级 + 收益管理对冲了大盘供给过剩**，但 OCC 同比降 1.2pp 印证「供给跑赢需求」的结构性承压。
- 结构性信号：截至 Q2 末三四线及以下在营门店占比升至 **44%**；中高端品牌在营及待开业同比 **+13.4%**；管理加盟及特许经营收入占比升至 **50.3%**。（来源：同上）
- 华住国际承压：OCC 70.5%（-3.5pp）、RevPAR 98 美元（-3.8%），受中东冲突与东南亚爬坡拖累。（来源：同上）

**2. 客群与价格分层**
- 暑期核心客群延续：亲子 / Z 世代 / 银发 / 带薪休假 / 入境 / 避暑旅居六类；华住上调全年指引（收入 +4%~8%，华住中国 +7%~11%），反映对下半年量价信心。（来源：华住财报 2026-08-17）
- 价格阈值：700 元成交阈值仍为分水岭（8/18 基线），高端山居（峨眉山悦榕庄均价 3000+）与大众连锁两极化。

## 二、民宿市场趋势（避暑旅居 / 设计感 / 在地感）

**1. 避暑旅居长尾爆发，从「网红」走向「长居」**
- 途家暑期数据：连住 **7 天**旅居订单同比 **+30%**、连住 **15 天 / 30 天**均 **+40%+**；**云南、贵州**旅居订单同比 **+52% / +41%**，青岛位列全国暑期民宿预订量第一。（来源：途家民宿暑期榜单 / 澎湃新闻 / 都市时报 2026-07~08）
- 连住 15 天及以上前十城市：昆明、大理、贵阳、威海、成都、六盘水、哈尔滨、青岛、曲靖、大连；**外国游客足迹覆盖 123 城**，伊犁 / 阿勒泰 / 黔东南 / 安顺 / 伊春民宿预订同比 **翻倍+**。（来源：同上）
- 客群结构：30–45 岁用户占比超五成；65 岁以上 +25%；超五成旅居订单选**多居室房型**。（来源：途家 / 都市时报 2026-07-21）

**2. 设计感 / 在地感成筛选维度**
- 途家上线首批「必住指南」覆盖 20+ 城，按**设计质感 / 在地风情 / 亲子适配**筛选；携程设计感酒店榜持续更新（广州上水精品设计酒店 No.12、桐庐 / 莫干山云溪上等）。（来源：途家 / 携程）

## 四、出圈设计感 / 高热度特色酒店

- **峨眉山悦榕庄（出圈样本）**：开业首周入住率 **92%**、均价 **超 3000 元/晚**，双遗产专线（乐山大佛 VIP + 峨眉山 VIP 接驳）**2888 元/人、首月预订超 80%**——「双遗产 + 高端山居 + 私汤」强溢价验证。（来源：今日头条 / 峨眉山悦榕庄开业报道 2026-08-15）
- **三亚亚特兰蒂斯（综合体标杆，基线延续）**：一站式水主题综合体，亲子 + 度假双引擎，暑期持续满房。（来源：8/18 基线）
- **携程设计感酒店榜**：广州上水精品设计酒店（从化温泉，起价 699，No.12）、桐庐云溪上（海拔 520 米云端山景）、莫干山云溪上（三面竹景）、三亚栖汐·西岛店（宠物友好）等。（来源：携程酒店榜）
- **阿里山英迪格（台湾）**：顶楼高空无边泳池 + 水疗池，以「阿里山无尽藏」为设计灵感，海拔 1280 米云海体验。（来源：interiormag 2026-01）

## 五、设计师酒店专栏（建筑师 / 主理人作品）

- **松赞昆明林卡（松赞体系）**：总体建筑面积约 **2.2 万㎡**，53 间客房 + 3 栋独立别墅，以「山水相依」重构自然意境，定位「喜马拉雅文化会客厅」，2/10 试营业。（来源：网易《在松赞昆明林卡》2026-02）

> 方法论：设计师酒店的共同溢价逻辑是「建筑即内容」——把不可复制的在地文脉转译为空间叙事，客人为「体验独特性」而非「标准奢华」付费。

## 七、当日趋势点评

1. **头部韧性 vs 大盘承压分化**：华住 Q2 RevPAR +1.1%、ADR 连续四季正增，但 OCC 微降 1.2pp——头部靠产品升级（全季 4.0 占 85%、中高端 +13.4%）与收益管理对冲供给放量，中小单体承压更明显，行业「K 型」加剧。
2. **奢华度假补位名山**：峨眉山悦榕庄首周 92%/3000 元，印证「双遗产 + 高端山居 + 温泉」强溢价；悦榕系持续下沉名山（峨眉/广州九龙湖），抢占高端度假空白。
3. **民宿旅居长尾化**：途家连住 15 天+订单 +40%、外国游客 123 城，避暑旅居从「网红打卡」走向「长居生活」，多居室/在地感/设计感成核心筛选维度，途家「必住指南」顺势上线。
4. **设计师酒店「建筑即内容」**：安达仕垂直街区、南京嘉佩乐 Chipperfield、杭州瑰丽如恩、松赞昆明林卡，均把城市/文明文脉转译为空间叙事，溢价来自「不可复制的在地性」而非标准奢华——这是酒店民宿内容创作（含 AI 漫剧）的高价值选题富矿。
