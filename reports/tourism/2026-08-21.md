## 一、政策与推广

**1. 暑期消费季收官在即，3 万场活动 / 4.5 亿补贴进入尾声。** 全国暑期文旅消费季 7 月初至 8 月底，累计举办超 3 万场活动、发放超 4.5 亿元消费补贴（文旅部、中国日报、证券日报，新浪财经 8/20）。8 月下旬市场转入"暑期答卷"复盘与"金九"预热衔接期。

**2. 上半年与 7 月大盘：总量稳增、结构优化。** 据文旅部数据中心，2026 年上半年国内出游 **34.63 亿人次（+5.4%）**、总花费 **3.21 万亿元（+2.0%）**；7 月单月国内出游 **12.3 亿人次（+18.7%）**、旅游收入约 **9200 亿元**（中国日报、经济参考报 8/20 综合）。暑期（7/1–8/20）预计同比增 **8%–10%**，呈"7 月第三周 + 8 月第一周"双峰延后特征。

**3. 离境退税 2.0 满月，入境消费写进顶层规划。** 上半年入境外国人 **2291.4 万人次（+20.4%）**，免签入境 **1781.5 万（占 77.7%，+30.6%）**；全国离境退税商店增至 **1.4 万家**、品种 356 类（增近 4 成）。地方成效：北京秀水街上半年入境 **430 万（+550%）**、销售 **20 亿（+350%）**；上海口岸退税 **25.3 万票（近 3 倍）/23 亿（+58%）**；深圳暑期入境 **6.9 万（+24.5%）**、免签占 61%（光明日报 8/20、深圳口岸数据）。即买即退、异地互认扩展至 28 天、无纸化办理持续落地。入境消费结构从"老三样"（茶叶/丝绸/工艺品）转向 **AI 硬件、原创 IP、智能穿戴"新三样"**（新浪财经、搜狐 8/20）。

**4. 地方推广动态。** 苏州 9 条措施促入境游（8/17 延续）；河北夏季旅游宣传推广（8/17）；江苏支持非遗小微企业文创（8/17）；东博会旅游展区聚焦"共创美好生活"（8/13）；第六届藏博会突出"文旅富民·产业兴藏"（8/13）。

**3. "奔县 + 慢充"成绝对主流。** 去哪儿：部分县域目的地酒店预订同比 **+500%**；4 天及以上出游人次占比由 28.4% 升至 **47.1%**；"慢游"标签搜索月环比翻倍、平均多 **2.3 天**；"奔县游"+63%、县域租车 +75%；县城高星酒店占比升至 **23%**（钱江晚报、腾讯 8/20）。成都居"奔县"客源地 TOP1（163.com 8/21）。四线及以下城市消费升级速度超三线 **11 个百分点**。

**4. 避暑"追凉"航线爆发。** "追凉"主题航线机票预订同比 **+5 倍**，芜湖–贵阳等航线 +5 倍；长白山国际度假区暑期酒店预订 **+195.96%**（去哪儿）。

**5. 入境消费高增、移动支付普及。** 支付宝暑期入境消费 **+72.9%**、微信支付 **+55%**；俄罗斯客源 +189.8%、张家界 +643%、重庆 +537%；深圳离境退税金额超 **10 亿（+130%）**（光明日报、深圳口岸）。

## 五、全球文旅标杆案例观察

### 案例 A｜西班牙毕尔巴鄂古根汉姆博物馆（Guggenheim Bilbao）—— 一个地标激活一座城

**背景：** 1997 年开馆，弗兰克·盖里设计，钛金属曲面解构主义建筑，选址内维翁河畔废弃工业码头。开业首年即吸引 **130–136 万** 游客，6 年收回 1 亿美元投资，年均游客 **100 万+**；2024 年对城市 GDP 贡献超 **6.5 亿欧元**，带动 **4500–9000 个** 就业岗位（古根汉姆效应，百科 / 光明网 4/2 / 中国经济网）。2004 年获威尼斯双年展最佳城市设计奖，2010 年获李光耀世界城市奖。

| 维度 | 观察要点 |
|------|----------|
| **空间设计** | 钛金属曲面 + 内维翁河工业码头选址，建筑本身即"可打卡的艺术品"；同步推动河道治理与交通升级，建筑与城市基础设施联动更新 |
| **文化叙事** | 以"装置级建筑"重塑城市身份——从"钢铁工业铁城"转向"文化艺术之都"，用一座美术馆重写城市 IP |
| **营收模式** | 门票（约 13 欧）+ 衍生消费（周边 / 餐饮 / 酒店）+ 全域旅游外溢；6 年收回投资，长期对 GDP 贡献超 6.5 亿欧，投资回报逻辑从"门票"转向"城市资产增值" |
| **客群运营** | 艺术游客 + 建筑打卡客 + 家庭客群，国际游客占比高；与城市其他博物馆形成"文化线路"联动留客 |
| **数字化技术** | 古根汉姆全球馆藏联网数字导览、建筑光影互动装置（具体系统「待核实」，建议后续核查其 AR/数字孪生应用） |
| **国内落地适配性** | 对标国内重工业城市转型、工业遗址改造：以"一座文化建筑驱动一片区复兴"替代"大拆大建"；适配东北 / 中部老工业基地"工业遗产 + 文化地标"城市更新路径 |

**一句话方法论：** 留量 > 流量——地标不是终点，而是城市资产增值的"总开关"。

### 案例 B｜日本豪斯登堡 Huis Ten Bosch —— 生态复原 + 夜游灯光经济的可持续度假区

**背景：** 1992 年开园，位于长崎佐世保填海地，占地 **152 公顷**，年游客 **250 万+**。以 1300 万颗 LED 打造的"光之王国（Kingdom of Light）"被誉为日本第一夜游灯光秀；园区种植 **40 万棵** 树木，配套先进污水处理、部分太阳能与填海地生态复原系统，并落地世界首家机器人酒店（eatmono.info / guidable.co / hey-japan.com）。

| 维度 | 观察要点 |
|------|----------|
| **空间设计** | 152 公顷荷兰风情复刻街区 + 运河体系，建于填海地并做生态复原，建筑密度低、绿地占比高 |
| **文化叙事** | "日本 × 荷兰"跨文化生活方式体验；以"填海荒地变绿色小镇"的生态修复叙事取代纯娱乐主题 |
| **营收模式** | 门票 + 夜游灯光经济（1300 万 LED 光之王国，日本第一）+ 机器人酒店 + 完善住宿过夜配套，年游客 250 万+，过夜率高 |
| **客群运营** | 家庭 + 情侣 + 夜游客群分层；住宿产品完善支撑过夜与复游 |
| **数字化技术** | 1300 万颗 LED 智能照明系统、机器人酒店（Henn-na Hotel）自助入住、园区智能节能与污水循环系统 |
| **国内落地适配性** | 对标国内大型主题度假区"重资产、低过夜"痛点：以绿色低碳 + 夜游灯光经济 + 住宿闭环提升过夜率；"生态复原"叙事适配国内滨水 / 填海 / 工业废弃地再生 |

**一句话方法论：** 减法比加法值钱——生态与夜游内容，比堆设施更能拉长停留。

**两案例对照：** 毕尔巴鄂证明"一个文化地标可激活整座城"（城市更新逻辑），豪斯登堡证明"生态 + 夜游内容可拉长过夜"（度假区逻辑），共同指向"内容资产 > 门票资产、留量 > 流量"。

## 七、国内文旅趋势深度观察

> 基线 2026-08-03。本期增量与变化如下。

### 7.1 城市微度假
- **临沂：存量活化 + 演艺留客。** 万兴都文创园年客流 1400 万+，1946 文创园年 15 万，水泥二厂遗址日均 5000+，沂州里 150 万；琅琊古城《国秀·琅琊》《国士·捍山河》全年 **2000 余场**、观演 **400 万**、人均二消 **200 元+**，以演艺延长停留。
- **乐山："周末下班直奔乐山"**（成渝后花园，8/11 发布会，四大举措 + 周末主理人盲盒）。
- **台州府城生活节**（驻留经济，包周包月模式）；**京郊夏夜微度假**（公园延时 + 营地 + 市集 15 分钟夜间生活圈）。

### 7.2 新兴特色小镇
- **龙宫桃子村：** 140 栋盘活 / 204 间流转 / 400+ 旅居 / **100% 入住** / 300 万+；黄果树过夜 **45.25 万（+27.3%）**。
- **白岩镇：** 24 套"国资 + 村委 + 农户"联营，"讲义人家"40 余房，民宿由 28 家整合为 11 家、年 10 万+，轻资产提质。
- **沧源葫芦：** 512 亩 / 218 栋 / 86% 使用率 / 400 万+；旅居 **4.1 万（+10.53%）** / 4800 万，沉寂资产转正标杆。
- **昭通：** 189 套 / 65% 出租率 / 1000 套目标；鲁甸安阁村 16 类场景 50 万+；桃苑 1000 套 2400 房、7 万+ 回头客 2.42 万；邵女坪 44 家民宿 / 494 床 / 户均 7 万。
- **盔林甲村：** 50 余栋 → 140 间"奎林山居"，6000+ 人次。

### 7.3 旅游度假区
- **抚松：** 万达"仲夏花火夜"单场 5000+（+197%）；华美胜地 43 万（+61%）；露水河收入 +24%；仙人桥 3300 人 / 140 万（+13.2%）。
- **湖北带：** 桃花冲 98%+（+28%）；百里荒 +20% / 青丘秘境 9000+；南津关 4 万（+22%）；龟峰山 6 万（+20%）。
- **荔波小七孔：** 8 月中上旬日均破 **6 万**。
- **乌江寨：** 平日 8000 / 周末 1.4 万 / 入住 80%–96%（详见六、陈向宏监测）。

### 7.4 趋势总结与方法论
延续"过夜率总开关 / 内容叙事优于重资产 / 减法比加法值钱 / 本地共建 / 负资产转正 / 票根连接器"框架，本期新增三则可复制要点：
