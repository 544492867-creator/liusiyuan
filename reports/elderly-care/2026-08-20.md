## 一、政策动态（国家 / 地方扶持、产业新规）

### 1.1 头号利好：长护险首次写入国家级五年规划，2030 年覆盖所有统筹地区
- **事件**：8 月 19 日，国家医保局公布《全民医疗保障"十五五"规划》，从 8 方面部署 26 条举措。长期护理保险作为**专项制度单独部署**：到 2030 年，长期护理保险制度将**覆盖所有统筹地区**，并提升长期护理服务能力和技术水平、促进长期护理相关领域创新。（来源：新华社 2026-08-19；央广网 2026-08-20；华西都市报 2026-08-20）
- **制度意义**：这是今年 3 月中办、国办部署"3 年左右基本建制"后，长护险首次纳入国家级五年规划并给出明确时间表。国家医保局规划财务和法规司副司长张晨光明确：各地按**全国统一制度框架、统一长护险服务项目目录、统一失能等级评估标准**推行；条件成熟后将探索**异地就医直接结算**。（来源：央广网 2026-08-20）
- **智能外骨骼首次写入长护险领域**：《规划》明确"促进智能外骨骼等智能化设备在长期照护领域应用"，系国家医保规划层面首次将智能外骨骼写入长期照护。（来源：证券时报 2026-08-20）这是康复辅具支付端突破的关键信号——目前北京、上海、江苏等十余省份已将医用外骨骼康复训练纳入医保或长护险试点（多为乙类治疗费，不含设备费）。

## 五、全球养老标杆案例观察（本期：丹麦 · 原居安老 Aging in Place）

> 维度拆解：运营模式 / 医养结合 / 智慧硬件 / 投融资 / 政策配套 / 本土化难点。丹麦系北欧福利国家原居安老典范，此前已覆盖荷兰生命公寓、日本介护、新加坡、美国 CCRC / PACE、德国多代屋、韩国、欧洲时间银行、英国退休村、加拿大逆按揭、澳大利亚退休村、法国、日本サ高住、中国香港，本期补丹麦。

### 5.1 运营模式：1987 年停止新建养老院，转向"原居安老"
- 丹麦 1987 年做出"停止新建养老院"的决定，核心理念是老人应在自己住了一辈子的家、熟悉的社区中安度晚年。体系由四大支柱支撑：
  1. **住房适老化改造**：老人申请、政府评估后出资改造（装扶手、防滑、拓宽门廊方便轮椅）。
  2. **24 小时居家护理**：护士 / 护工定期上门助浴、换药、康复训练、临终关怀，需要时 30 分钟内可达。
  3. **社区日间照料中心**：白天就餐、活动、康复、社交，晚上回家。
  4. **预防性健康管理**：定期家访评估身体变化，及早干预，延缓滑向失能。
- **成本账**：人均养老支出比机构模式低约 1/4——省下机构硬件与运营养老院的钱，前置投到适老化改造与预防，前端花得多、后端花得少。（来源：颐联社 / impact-guru 北欧模式研究）

### 5.2 医养结合与《老年法》
- **《老年法》（ældreloven）2025 年 7 月生效**，创设专门老年人照护法律框架，强化自决权、连续性、对专业判断的信任及与家属 / 社区协作。
- **复原式照护（Reablement）**：丹麦最 influential 的社区照护元素，短期、目标导向，帮助老人病后 / 衰退后恢复或维持日常生活能力（而非工作人员直接代劳）。需照护员、治疗师、护士、评估师多学科协调；成功以"功能能力 + 信心 + 参与度"衡量，而非康复次数。强调区分"恢复 / 维持 / 补偿性照护"，对渐进性疾病、重度失智不以能力测试施压。（来源：Impact Guru / Ældre Sagen / 网易"老有记"）
- 养老责任主体为 **98 个市政区（municipalities）**，由市级评估确定服务类型、强度、住房与预防支持。

### 5.3 智慧硬件与适老化
- 适老化改造属公共服务，按个体需求配置扶手、洗浴设备、升降装置、入口改造等；数字设备进入居家私密空间（跌倒监测、远程照护），强调"尊重家宅 + 雇主对worker安全责任"的平衡（积极风险承担 positive risk-taking）。
- 居家成"工作场所"与私人空间叠加，要求风险共担、协商而非强制。

### 5.4 投融资与政策配套
- **税收筹资（tax-funded）**，无独立长护险缴费；老年人照护主要通过一般税收由市政区提供 / 安排，按**评估需求**而非个人资产获取，亲属不须先耗尽资产。
- **LTC 支出约 3% GDP**（含健康成分），为 OECD 最高之一（仅次于挪威）；2024 医疗改革 + 老年照护改革 2025—2027 分阶段落地， fiscal cost 约 0.25% GDP（2027 起）+ 2026—2035 投资 0.9% GDP。
- 2024 老年照护改革：减行政负担、一人一责协调居家护理 / 康复 / 居家照护，扩大社会与医疗教育供给。

### 5.5 本土化改造难点（对中国镜鉴）
1. **高税收前提不可复制**：北欧税率 40%+，中国不具备；但"政府买单、市场提供服务"的竞争机制可抄（适老化改造免费化中国正推进）。
2. **"家庭回归"（Familial Turn）**：机构准入标准提高，中度失能老人回流家庭，照护责任部分回到家庭，"三明治一代"（中年女性）三重负担上升，挑战性别平等——与中国"9073"居家为主、家庭照护压力高度相似。
3. **复原式照护的理念张力**：从"基于需求的权利"转向"基于能力"，老人须持续证明无法独立生活方可获服务，资源约束下重新解释普惠主义——提示中国长护险评估标准设计须平衡"防依赖"与"保尊严"。
4. **可迁移三件事**：① 适老化改造从老人自费变公共服务（社区统一推进、藏进设计）；② 居家护理从家属负担变专业服务（长护险应让"在家即报销"而非"必须入住机构"）；③ 社区日间照料从"做样子"变真实服务网络（上海长者照护之家 / 综合为老服务中心方向正确但覆盖率差距大）。
- **镜鉴青岛与万宁阿那亚**：丹麦"把服务送到家、不离开熟悉社区"的逻辑，与青岛"中国康湾"全龄健康社区、万宁阿那亚"全龄健康 + 10 年运营承诺 + 医疗可携"高度契合——均强调"不离家 / 不离社区"的照护网络，而非集中机构；但丹麦靠高税收+98 市政区落地，青岛须靠"自持运营 + REITs + 长护险支付"的市场化组合补位。

## 六、国内养老案例深度观察（综合体 · 项目 · 小镇）

### 6.1 养老综合体 / CCRC：城心模式跑通、盈利拐点显现
- **大家的家（大家保险）**：业内率先深耕"城心养老"，截至 2026-05-31 全国在营社区 **12 家**；北京友谊 / 朝阳等成熟社区入住率**接近 100%**，天津泰安道开业不足两年入住率**超 95%**，全国平均入住率**超 70%**（行业平均约 45%）；首个社区已跑通财务盈亏平衡，形成"负债端 + 投资端 + 生态端"三端协同可持续模式。存量盘活：改造闲置酒店 / 办公楼 / 商业体（武汉东湖 1998 年办公楼焕新），契合十五五"城市更新"与"旧改 + 养老"。（来源：中国经营网 2026-06-17；新浪财经 2026-07-10）
- **太保家园·上海普陀**：2023-09 开业，近 4 亿元、1.7 万㎡、288 床；2026 入住率**突破 90%**，客户满意度 98.6%，再入院率 3.2%，康复有效率 85%+，预计 2025 年盈利——"城央康养"商业闭环样本。争议点：288 床规模 + 仅 3 层，"小而美"还是"精致盆景"？聚合效应受限。（来源：搜狐焦点 / 腾讯新闻 2026-08-14）
- **泰康之家**：全国 27 社区（基线维持），远郊"长寿社区" + 城市核心区中小型康养项目多层级网络，覆盖不愿离原生活圈的高龄高照护客群。
- **平安居家（轻资产）**：覆盖 140 城、31 万资格客户，9.7 倍保单价值杠杆——验证"保险 + 居家养老"轻资产路径（见 2.2）。

### 6.2 特色养老项目：物业 + 康养、机器人驿站维持基线
- 亦庄全球首个智慧康养机器人养老驿站（3/12 运营）持续作为"场景兑现"标杆；招商积余物业 + 康养"111N+336"体系（武汉验收、多城复制）维持前期观察。
- 社区嵌入式小微机构、旅居康养基地（黑龙江避暑、宜兴阳羡、安吉天使等）本期无新公开重大动态 → **维持前期观察**。

### 6.3 养老小镇：文旅 + 养老融合路径
- 宜兴阳羡生态旅游度假区、安吉天使小镇、桐庐瑶琳仙境康养镇、海城腾鳌 95 浪漫小镇等"低改造 + 强叙事 + 本地共建"路径本期无新增公开数据 → **维持前期观察**（基线：宜兴雅达阳羡溪山 2000 床 / 约 1 万月，安吉长三角康养旅居试点）。
- **新增关联信号**：联合国康养旅居会议落地重庆江津（8/19—21），发布"江津案例"+"四面山富硒康养民宿团体标准"，国际机构首次为中国县域康养旅居背书，为"生态资源 + 团体标准 + 金融对接"县域样板——与养老小镇"强叙事 + 标准化"路径同源，值得小镇项目对标。

## 七、银发经济趋势与客群观察

### 7.1 客群趋势变化
- **60 后"新老人"悦己消费**：50—65 岁"新老人"约 2.5 亿，改革开放成长、教育 / 资产更优、消费从"省吃俭用"转向"品质 + 悦己"，健康养护 / 自我实现需求上升。
- **70 后准老年群体提前规划**：41—50 岁职场人群成消费主力（青岛数据：2025 康养消费中 41—50 岁占比突出），未老先养、备老意识前移。
- **80+ 高龄刚需升级**：失能 / 半失能超 4000 万，照护刚需扩容；女性占比约 74%，城乡 / 区域差异显著（城市老人年收入 4.7 万、21% 贡献 74% 线上消费）。
- **全龄健康前置**：30 岁以下康养消费参与者占 14.3%，"适老不唯老"成共识（青岛"中国康湾"逻辑）。

### 7.2 经济发展趋势变化
- **细分赛道增速对比**：银发经济主口径 10.8 万亿（+15.2%）显著高于 GDP 增速；居家社区（4.2 万亿）、健康管理（2.8 万亿）为高增板块；智慧养老（7.85 万亿口径待核实）、康复辅具受政策 + 技术双驱动。
- **支付端演进**：长护险 2030 全覆盖写入十五五规划（支付确定性增强）；消费券（广东失能月最高 800 元）、商业养老保险、适老化改造纳以旧换新多管齐下。
- **科技赋能**：智能外骨骼零售额 H1 +458.4%、机器人产业 H1 +24.5%、60+ 网民 1.61 亿（52.0%），AI + 养老落地从演示走向"场景兑现"（结对攻关清单）。

### 7.3 特色内容观察（银发网红 / 短视频 / 直播）
- **创作侧爆发**：抖音《2026 银发用户创作报告》显示 60 岁以上发视频数量增速登顶；粉丝超 400 万老年网红超 20 人；#爷爷奶奶 话题播放超 100 亿次；八旬清华奶奶访谈视频播放超 4000 万。
- **带货侧实证**：沙市老姨妈 9 人月销近百万（4.1）、银发主播 GMV 整体 +350%、田姥姥单场 150 万 / 汪奶奶 1300 万粉、周大爷 1807.5 万粉、蒙阴 / 东乡 / 兖州"银发带货"下沉。
- **内容设计四原则**（持续适用）：大字 / 高对比 / 慢节奏 / 强陪伴感；**反年龄叙事**（"主动享老"而非"被照顾"）；合规拐点（75% 冲动消费、白牌益生菌周销近万，须防虚假宣传）；与 **AI 漫剧选题关联**——银发情感共鸣 + 代际共创内容易出圈。

## 八、青岛康养地产政策专项（新增 2026-08-11 起）

### 8.1 政策基线（维持）
- **核心文件**：《青岛市支持康养地产高质量发展若干政策措施》（11 条），2026-07-06 印发、07-22 青岛政务网公布、07-23 市政府新闻办发布会。
- **五类项目认定标准**（试行）：旅居康养 / 养老护理型 / 理疗康复型 / 健康养生型 / 复合型；覆盖新建 + 改建，须满足用地、房屋、配套、综合服务、运营管理 5 方面基本要求，运营承诺**不少于 10 年**。
- **四个维度核心条款**：① 规划配套 650㎡/千人建健康服务中心（≥1000 套项目最小 3500㎡，其他 1000㎡），自持运营不得分割；② 降成本 健康服务中心计容不计价、土地款分期最迟 1 年、缴 50% 且承诺 6 个月开工可提前交地、"正负零"即可预售、装配式 3% 不计容；③ 融资渠道 养老再贷款最长 3 年、年利率 **1.25%**，支持险资股权 / 债权 / 产业基金 / REITs；④ 品质保障 水电暖气可执行居民价、医保定点评估、医养结合嵌入式服务延伸至社区居家。
- **配套政策**：曾赞荣《学习时报》08-05 署名文章（全链条政策 / REITs / 长护险先行）；市南 40 项举措；"中国康湾"三年行动（2027 破 1000 亿 / 2026 15 项目 87 亿 / 险企 14 亿）；市民政局"五床联动"；19 项省市政策体系。

### 8.2 本期（2026-08-20）动态
- **本期无青岛市级新康养地产政策文件发布** → 明确标注"**无公开新增动态，维持前期观察**"。
- **实施进展追踪**：① 三大标杆项目加速落地——龙湖上合国际康养未来城（胶州少海，11 亿，CCRC，270 床，椿山万树运营，健康服务中心主体完工）、海信璟悦康养公寓（崂山张村河，2.8 亿，24 层商办改 87 套产权公寓 + 18 床）、君一全龄社区（崂山王家村，16.9 亿，350㎡ 邻里坊，引入盈康医院，主体过半）；② "中国康湾"入选国家银发经济典型案例、综合能力"领跑级"；康复大学（全国唯一）为人才芯片；③ 康养机器人训练场 45 企 217 台、意向合作 7000 万；④ 全市养老机构 298 家、社区养老设施 1200 余处、家庭养老床位 9.8 万张、失能消费券 17.8 万张拉动 3.6 亿。

### 8.3 影响评估
- **对青岛本地项目**：11 条政策直击"前期投入大、回报周期长"痛点，三种路径（专业品牌运营 / 存量改造轻资产 / 制造医疗资源赋能）均已获政策与金融支撑；"自持运营 + 10 年承诺"从制度上确保长期深耕。
- **对万宁阿那亚等异地项目参考价值**：① 全龄健康定位（"适老不唯老"）× 万宁阿那亚"阿那亚业主父母 70 岁+ 银发客群"高度吻合；② 10 年运营承诺 = 万宁"长期主义 + 社区运营"逻辑；③ REITs / 险资通道 = 重资产康养退出路径；④ 医疗可携 + 长护险支付 = 异地康养最关键的"医疗配套"痛点补位。
- **对全国示范意义**：全国首个城市级康养地产系统性支持政策，被第一财经等作为"全国参照系"（吉林 / 云南 / 海南 / 烟台竞逐"抢老人"）。
- **政策落地挑战（维持 4 项）**：① 医疗配套依赖本地三甲与康复资源，非所有城市可复制；② 自持运营考验长期现金流，险企外主体承压；③ 950 万护理员缺口（行业口径）制约服务供给；④ "商改住"去化仍受楼市周期影响。
