## 二、民宿市场趋势（避暑旅居 / 设计感 / 在地感 → 节后降温与监管出清）

**双节"在地慢游"全面压倒"特种兵打卡"，但节后 W41–W42 民宿端降温延续并深化，K 型分化 + "床车分流" + "连锁酒店下沉替代"三重新变量共振。** 国庆实测与节后复盘（网易 / 腾讯新闻 / 今日头条 2026-10-08 至 10-15 延续）显示，民宿并非全线下滑，而是"头部稀缺景观精品稳、中间同质化模板崩"的结构性出清：

- **途家**（延续）：连住 3 天及以上订单同比 **超五成**；"95 后 / 00 后"订单占比 **超 45%**；约 1/5 游客在两座及以上城市订民宿。
- **木鸟**（延续）：连住 7 天及以上订单同比 **+30%**；三线及以下城市日均订单 **+17%**；家庭游订单占比 **53%**。
- **节后降温实证（网易 / 腾讯新闻 / 今日头条，2026-10-08 至 10-15 延续）**：大理全州 **10.32 万张民宿床位**（截至 2025 年底，澎湃 / 大理官方口径），国庆期间平均入住率仅 **50%–55%**；丽江五千多家民宿旺季入住率从往年七成多**跌到三成到四成**；莫干山曾三千一晚的精品民宿国庆降到**八百出头**；整租民宿均价较两年前**跌三成多**。预订高峰仅集中在 10.2–10.4 三天，5 号之后人流明显下滑。重庆解放碑、乌镇、凤凰古城等老牌网红民宿聚集地情况基本一致，中端民宿从国庆千元价位降到两百元左右、低端跌破百元仍空置率超 50%。
- **K 型分化**（迈点 / 媒体归纳，延续）：头部高端精品、带独家景观特色民宿入住率仍稳定 **75% 以上**；承压的是占绝大多数的中端 / 大众民宿——普通民居改造、无特色、服务参差，入住率同比掉 **10–15pct**。"50 元 / 床位仍无人住"极端案例在云南、江苏、福建、广西多地出现（网易 / 腾讯新闻，延续）。
- **供给侧洗牌**（行业观察，非官方网签，沿袭）：截至 **2026 年 5 月全国民宿相关企业 40.3 万家**（企查查口径，腾讯新闻 2026-10 转载，较 2025 年底 38.3 万家口径上修）；**中国旅游协会数据称 2025 年 10 月全国民宿平均入住率 36%、均价 367 元（较 2024 年 489 元降约 30%）**；2025 年新注册约 **8.6 万家**、注销 / 吊销约 **2.9 万家**。十年间全国民宿企业从不到 2 万家膨胀到超 40 万家（今日头条 / 网易专题，2026-10）。
- **"床车分流"新变量**（今日头条 / 小红书，2026-10 延续）：大量自驾游客直接睡在新能源车里（座椅放平 + 驻车空调），"床车自驾游"话题阅读量**破 1.1 亿**，甘肃等地高速服务区集中过夜上百辆——以"充一次电十几块"替代千元住宿，对普通民宿形成增量分流（延续）。
- **连锁酒店下沉替代（本期强化）**：汉庭 / 全季 / 亚朵在大理、丽江、苏州等热门旅游城市国庆期间始终保持满房，价格未大幅跳水甚至小幅上涨（网易 / 今日头条 2026-10-08）。"酒店满房、民宿空置"的价格倒挂，标志标准化连锁对同质化民宿的替代效应进入显性化阶段。

**监管规范化成为 2026 产业升级核心抓手（本期重大新增：湖南省民宿条例落地）**：
- **《湖南省民宿条例》——全国首部以民宿为主要规范内容的省级地方性法规（本期重点）**：2026-09-23 经湖南省人大常委会通过，自 **2027-01-01 起施行**（湖南人大网公告第 90 号；湖南省人民政府 2026-09-25 发布会）。核心条款：① **禁开红线**——城镇住宅小区四层以上禁开民宿，四层以下须利害关系业主一致同意，直接回应"住改商"扰民与消防痛点（人民日报·金台视线，2026-10-12）；② **平台责任前移**——OTA 须实名登记并核验营业执照 + 特种行业许可证，对违法信息停止服务 / 报告；③ **消费者保护**——明码标价、禁强制搭售、仅**公共区域**可装监控，划定隐私边界（湖南省市场监督管理局 / 中国消费者报，2026-10-12）；④ **安全准入**——消防不达标须改造，禁地质灾害高风险区 / 违法建筑开办；⑤ **鼓励特色化、集群化、康养旅居复合业态**。其意义在于标志民宿治理从原则走向"准入—经营—平台—协同"全链条（人民日报引西南政法大学张力点评）。
- **四川雅安**：《雅安市民宿促进和管理若干规定》2026-09-10 市人大通过、2026-09-24 省人大批准，将于**明年 1 月正式施行**——省内首部民宿专项法规（延续）。
- **云南**：《云南省旅馆业治安管理实施细则》**自 2026-10-01 起施行**；文山州公安局明确网约民宿 / 公寓须取得营业执照并申领特种行业许可证（延续）。
- **广东 / 多地**：珠海万山《民宿管理办法（试行）》（珠万管〔2026〕11 号）、江门《民宿管理暂行办法》（2026-05-09 施行）落地（延续）。
- **行业治理逻辑转变**（北方网，2026-08-24，延续）：全国民宿建立"属地管理、部门联动、行业自律、社会监督"四维监管体系。中国旅游新闻网指出当前民宿供给矛盾是"低品质过多、同质供给过剩、有效供给不足"，卫生不达标、隔音差、隐私弱、图文不符、服务不稳定仍在劝退客人。

**趋势判断**：湖南省条例的示范效应 + 连锁酒店下沉双向挤压 + "床车自驾"增量分流，民宿行业正从"颜值 / 流量竞争"转向"合规 / 品质 / 特色竞争"。短期看，节后淡季（W41–W42）普通民宿空置率或进一步走高；中长期看，品牌化、连锁化、特色化头部玩家将做大，中间层持续出清。监管"负面清单 + 平台实名核验"组合，将加速"无效供给"出清，利好合规精品。

## 七、当日趋势点评

1. **W41 周报落地 + 大摩确认，四季度"QTD RevPAR +2.6%"与"Q4 转正"成为本期最关键增量信号**。截至 10-15 抓取，腾讯"2026年10月第2周酒店数据跟踪"（10-12 22:20 发布）给出节后周度框架：因假期错位周度同比失真，改用 QTD 口径——四季度至今 RevPAR **+2.6%**（三季度 +1.1%），国庆酒店公司反馈"持平到微增"。**本期新确认**：大摩（10-12）指 9 月积极势头延续至 10 月、预期华住 Q4 RevPAR 转为正增长，升华住目标价至 47 美元——外资行与周度数据相互印证，四季度"企稳微增"判断强化。
2. **量价背离仍是本期最稳固结论，但"量"的弹性超预期**。飞猪日均履约间夜 **+70%**、超百城翻倍、高星间夜 **+80%+**；美团连住订单 **+31%**；中国饭店协会 72.7% 企业入住率增或持平——"量"强；但第一财经国庆大盘 RevPAR **−2%**、中国饭店协会平均房价 **−8.7%**——"价"弱。"以价换量"是双节主线，节后 W42 价格端或在双11 套餐对冲下边际企稳。
3. **会员 / 高星成为品质住宿核心引擎（延续 + 双11 强化）**。飞猪 88VIP 人均酒店消费高 34%、高星间夜 +80%+，超 70 个品牌旗舰店间夜翻倍，新入驻商家日均间夜较五一 +135%——平台会员体系正从"销售渠道"升级为"高质量会员获取阵地"。双11 万豪 / 希尔顿 / 雅高套餐普遍含 SNP 积分权益，进一步绑定会员复购，高星与品牌酒店受益最明确。
4. **供给侧"环比收缩"信号延续，产能过剩矛盾未解**。OTA 酒店 104.2 万家（环比 −1.0%）、客房 2335.4 万间（环比 −0.9%）较 W40 双降；头部集团门店较上周合计净减（华住 −46 / 锦江 −17 / 首旅 −14 / 亚朵 −3）——尾部出清 + 节后摘牌微调，但同比 +24.8% 高基数意味着产能过剩矛盾未根本缓解，W42 继续观察环比收缩是否延续。
5. **档次与线级结构分化延续，高星靠会员抗跌、大众靠降价求生**。新浪 W40 奢华 −11.5% / 中高端 −9.5% 跌幅最深（10-13 沿用）；但飞猪高星间夜 +80%+ 显示"高星总量扩容、头部集中度提升"与"平均房价回落"并存——高星内部的品牌 / 区位分化正在加剧。分线级看，一线 +1.7% 一枝独秀，新一线以下普遍负增长，强资源型县域（嘉兴南湖、平湖等）借国际品牌下沉获得增量。
6. **民宿两极分化 + "床车分流" + "连锁下沉替代"三重新变量，出清加速**。大理 10.32 万床位仅 50%–55% 入住、丽江跌至三成到四成、莫干山降至八百出头（延续）；中国旅游协会 2025-10 全国民宿平均入住率 36%、均价 367 元（较 2024 降 30%）；"床车自驾游"话题阅读破 1.1 亿；汉庭 / 全季 / 亚朵在热门旅游城市满房——中间层闭店潮压力进一步上升。
7. **监管升级：湖南省民宿条例成全国首部省级专项法规，治理从原则走向全链条**。2026-09-23 通过、2027-01-01 施行的《湖南省民宿条例》明确"城镇住宅小区 4 层以上禁开民宿、4 层以下需利害关系业主一致同意""平台实名核验营业执照 + 特种行业许可证""仅公共区域可装监控"等硬条款，对"住改商"扰民、偷拍、图文不符等痛点精准回应。其示范效应叠加雅安 / 云南 / 珠海 / 江门细则，持续抬高准入门槛、加速无效供给出清。
8. **集团分化：锦江"全资维也纳"收官，亚朵零售、华住规模、首旅管理三条路径延续；券商三季报前瞻偏谨慎乐观**。锦江拟 8.11 亿收购维也纳及百岁村餐饮各 10% 股权（9-29 公告），完成后持股 100%、十年累计耗资 27.77 亿、维也纳 2026H1 营收 16.87 亿 / 净利 2.30 亿。新浪三季报前瞻给华住 / 锦江 / 首旅 / 君亭 / 金陵 26Q3 归母净利增速 **0%~5% / 10%~20% / −5%~+5% / −20%~−5% / −5%~+10%**——存量经营承压（华住中国成熟酒店同店 RevPAR 下滑）仍是行业共性挑战，但 Q4 企稳信号已在周度数据显现。
9. **国际品牌入华"二次爆发"进入密集兑现期，下沉 + 首店双线推进**。2026 年至少 9 个国际酒店新品牌首店在华落地（佳阁北京 798、新罗汇纹西安、苏州艺刻、天津柏典、凯悦嘉迎、凯悦悠选金华、美高梅美幻深圳、希尔顿西嘉、平湖万豪臻品之选县级市首店），万豪 2025 大中华区签约超 200 项目（同比 +25%）、洲际在华 14 品牌 1500+ 家；华住与广州国资计划 3 年落地 300 家酒店 / 100 亿——内外资在"强资源型目的地 + 存量盘活"赛道贴身肉搏。
10. **海南封关后首个国庆免税 "量价仍弱但热度确认"，W42 进入淡季观察窗口**。10.1–7 离岛免税 8.55 亿元 / 12.3 万人次（+10.41%）/ 近 70 万件，较 W40（10.1–5）6.48 亿上修，人数增速由 +13.35% 收窄至 +10.41%，"客流强、客单弱"延续但封关红利初显。节后 W42 三亚等地整治违规赶海（关停 7 家、立案 5 家），目的地治理趋严。
