#### 2.1 访谈梗概
- 梗概：杨东（清华学霸/早期VC/财商书作者）× 凉子 —— 财商教育不是教人算计，而是教人理解"创造"与"系统"

| 层级 | 内容 |
| --- | --- |
| 人物设定 | 杨东，无明确人生规划"拍着脑袋走"；本科计算机、留美转经济、读会计硕士进投行；90年代末香港投行月薪两万多港币，却因"体力活"转投VC |
| 核心冲突 | 投行高薪 vs 无意义感；"算计"式财商 vs "创造"式财商 |

#### 2.2 核心观点
1. **财商教育的本质是"创造"而非"算计"**：杨东反对把财商简化成省钱/理财技巧，强调理解价值从何而来。
2. **投行是"体力活"不是"脑力活"**：高薪背后是巨量文件与数据核对，长期消耗让人想逃离——高收入不等于高意义。
3. **VC 的吸引力在于"圈子小、竞争不激烈"**：他形容早期中国VC"没事赚点钱偷着乐挺好的"，与投行的高压形成对照。
4. **用"操作系统"隐喻理解垄断**：他抛出"世界上如果有十个操作系统，不就乱了吗"，指向标准与生态的稀缺价值。
5. **教育要回到"自由探索"**：他感谢父母给的自由空间，认为这是自身最大的运气。

### 节目二：《The Diary Of A CEO》× Seth Godin

- **对谈人**：Seth Godin，畅销书作家、营销大师，代表作无数；本期带来新书《The Knot》

#### 2.1 访谈梗概
- 梗概：Seth Godin（营销大师）× Steven Bartlett —— 放弃不是失败，是一种被低估的超能力

| 层级 | 内容 |
| --- | --- |
| 人物设定 | Seth Godin，畅销书作家、营销思想家；强调"帮助人找到描述问题的词汇" |
| 核心冲突 | 完美主义/沉没成本让人卡住 vs 识别"问题还是处境"后战略性放弃 |
| 论证主线 | 区分 problem 与 situation → 放弃是 superpower → AI 时代"最人性"的能力更稀缺 → 用《The Knot》的隐喻谈连接与承诺 |
| 情绪落点 | "You can quit. Quitting is a superpower." 反鸡汤，强调主动选择 |
| 独特信息 | 他主张"我不替人解决问题，人自己解决"；AI 时代真正稀缺的是 human qualities |

#### 2.2 核心观点
1. **放弃是一种被低估的超能力**（strategic quitting）：不是所有坚持都值得，"Quitting is a superpower"。
2. **区分"问题"与"处境"**：问题是可解决的，处境只能与之共存；先判断再行动。
3. **完美主义常让人卡住**：人们害怕被评判，但看清系统（如大学录取的"游戏本质"）后戏剧感就退场。
4. **AI 时代"最人性"的能力更值钱**：当AI接管重复智力劳动，人的连接、判断与勇气反而稀缺。
5. **他的角色是"给词汇"而非"给答案"**：帮人找到描述问题的语言，人自己向前。

- 【Seth Godin】"All problems can be solved. Some things aren't problems. They're situations, and you have to live with them."
- 【Seth Godin】"I don't solve problems for people. They solve problems for themselves."
- 【Seth Godin】"Once you see the college industrial complex … all the drama moves to the side."

## 三、栏目模式拆解

**1. 《凉子访谈录》—— 苦难样本共情**
- 内容定位：普通人的自我、创伤、抉择、和解；不看名气看人生样本。
- 提问框架：长时段对谈，让嘉宾把伤口扒开（杨东谈"体力活"式觉醒、毕夏谈丧夫）。
- 剪辑节奏：视频专访 + 图文实录双轨，金句切片二次传播。
- 流量密码：极致真实（"你就走吧""世界上如果有十个操作系统"）+ 身份反差。

**2. 《The Diary Of A CEO》—— 证据派 + 反直觉钩子**
- 内容定位：跨地缘/财富/健康/金融/心理的高密度专家访谈。
- 提问框架：先问"听众离开时能回答什么问题"，再展开证据链。
- 剪辑节奏：完整长访谈 + "Most Replayed Moment"高光重剪多入口。
- 流量密码：反直觉一句做3秒钩子（Godin "Quitting is a superpower"）+ 数据为锚。

**3. 《张小珺商业访谈录》—— 第一性原理型商业深访**
- 内容定位：描摹时代的商业、文化、新知；以"行业潜规则摊开"为核心承诺。
- 提问框架：从具体人物故事切进技术/商业第一性原理。
- 剪辑节奏：长音频为主，视频播客同步；靠 OUTLINE 时间线做轻量化导航。

**4. 《On Purpose》—— confessional 自我揭露**
- 内容定位：心理/关系/自我成长型对谈。
- 提问框架：以"你卡在哪"切入，引导嘉宾自我揭露。
- 流量密码：一句可转发的生活洞察（"Quitting is a superpower"同赛道）。
