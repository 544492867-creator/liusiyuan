## 三、消费数据与趋势

**1. 暑期大盘总量与结构双优。** 2026 暑期（7–8 月）国内出游预计 **11.2 亿人次（+32.7%）**、旅游总花费约 **1.55 万亿元**，亲子客群占比约 **62%**、入境游预订同比 **+612%**（携程、去哪儿、飞猪，8/24 抓取）。

**2. 平台全线飘红。** 飞猪暑期热度 **+40%**，亲子 +31%、大学生 +58%；携程亲子游 +13.6%、同程亲子类 +45%；上半年入境游订单 +49.72%、门票 +231.41%（携程研究院）。

**3. "奔县 + 慢充"成绝对主流。** 去哪儿：部分县域目的地酒店预订同比 **+500%**；4 天及以上出游占比由 28.4% 升至 **47.1%**；县城高星酒店占比 **23%**（钱江晚报、腾讯 8/24）。

**4. 大交通高位运行。** 国铁集团：7/1–8/31 全国铁路预计发送旅客 **10.1 亿人次、日均 1629 万**（经济参考报 8/17）。

**5. 入境移动支付普及。** 支付宝暑期入境消费 **+72.9%**、微信支付 **+55%**；俄罗斯客源 +189.8%、张家界 +643%、重庆 +537%（光明日报、深圳口岸 8/24 抓取）。

## 五、全球文旅标杆案例观察

### 案例 A｜新加坡圣淘沙"大圣淘沙岛愿景"（GSMP，8/24 公布）—— 海岛目的地的"扩容 + 交通重构"

**背景：** 新加坡总理 Lawrence Wong 在 8/23 国庆集会宣布、8/24 正式公布"大圣淘沙岛愿景（Greater Sentosa Master Plan, GSMP）"：将圣淘沙与 **120 公顷** 布拉尼岛（Pulau Brani）融合开发，建成后整体游客量预计达目前 **两倍**；核心项目含英比奥天幕（Imbiah Lookout canopy）、"岛屿之心"交通枢纽、Downtown South 度假村（NTUC）、新捷运系统 + 水上出租（so.html5.qq.com / sg.yahoo.com，8/24 抓取）。

| 维度 | 观察要点 |
|------|----------|
| **空间设计** | 圣淘沙 + 布拉尼岛 120 公顷联动，以"岛屿之心"交通枢纽重组动线；英比奥天幕打造新地标观景界面 |
| **文化叙事** | 从"主题乐园岛"升级为"综合度假群岛"，以扩容叙事维持国际目的地竞争力 |
| **营收模式** | 度假村（Downtown South/NTUC）+ 新捷运 + 水上出租 + 多元住宿过夜，目标游客量翻倍，过夜与复游双增 |
| **客群运营** | 国际家庭 + 区域度假客 + 本地周末客分层；水上交通 + 捷运提升岛内流转效率 |
| **数字化技术** | 新捷运系统、水上出租智能调度（具体票务/数字系统「待核实」） |
| **国内落地适配性** | 对标国内海岛度假区（海南、舟山、横琴）：以"岛群联动 + 交通重构 + 度假村过夜"替代单岛景点模式 |

**一句话方法论：** 海岛不止于景——交通重构 + 度假村过夜，才是游客量翻倍的底层杠杆。

### 案例 B｜日本豪斯登堡 Huis Ten Bosch —— 生态复原 + 夜游灯光经济的可持续度假区

**背景：** 1992 年开园，位于长崎佐世保填海地，占地 **152 公顷**，年游客 **250 万+**。以 1300 万颗 LED 打造的"光之王国"被誉为日本第一夜游灯光秀；园区种植 **40 万棵** 树木，配套先进污水处理与生态复原系统，并落地世界首家机器人酒店。

| 维度 | 观察要点 |
|------|----------|
| **空间设计** | 152 公顷荷兰风情复刻街区 + 运河体系，建于填海地并做生态复原，建筑密度低、绿地占比高 |
| **文化叙事** | "日本 × 荷兰"跨文化生活方式体验；以"填海荒地变绿色小镇"的生态修复叙事取代纯娱乐主题 |
| **营收模式** | 门票 + 夜游灯光经济（1300 万 LED 光之王国）+ 机器人酒店 + 住宿过夜配套，年游客 250 万+，过夜率高 |
| **客群运营** | 家庭 + 情侣 + 夜游客群分层；住宿产品完善支撑过夜与复游 |
| **数字化技术** | 1300 万颗 LED 智能照明系统、机器人酒店自助入住、园区智能节能与污水循环系统 |
| **国内落地适配性** | 对标国内大型主题度假区"重资产、低过夜"痛点：以绿色低碳 + 夜游灯光经济 + 住宿闭环提升过夜率 |

**一句话方法论：** 减法比加法值钱——生态与夜游内容，比堆设施更能拉长停留。

**两案例对照：** 圣淘沙证明"岛群联动 + 交通重构可翻倍游客量"（目的地扩容逻辑），豪斯登堡证明"生态 + 夜游可拉长过夜"（度假区逻辑），共同指向"内容资产 > 门票资产、留量 > 流量"。

## 六、⭐ 陈向宏典型作品监测

### 6.1 监测对象与范围
本期系统监测四大矩阵：乌镇（东栅 / 西栅）、古北水镇、濮院时尚古镇、乌江寨。基线：乌镇 1–6 月入境 26.23 万（+67%）、桐乡 1–5 月入境 25 万（+66%）为参照锚点。

### 6.2 业态监测
- **乌镇：** 第十三届戏剧节 8/22 首轮开票《野鸭》1 分钟售罄，本届 26 部、74 场、11 国，**9/5 开启第二轮开票**（乌镇戏剧节官方，8/24 抓取预告）；消夏节"凉街踩水 + 泡泡夜游神 + 古镇嘉年华"；机场行李代取双向转运"空手出游"。
- **古北水镇：** 司马台云雾节"五凉"体系，长城星空营地，多语种导视系统，外籍游客 +87%（云雾节期间）。
- **濮院：** 泼水夜摇免费区（至 8/31）日近万人，水街客流 2 倍、水域 +70%；"2026 折纸计划"近 30 位国际折纸巨匠驻场。
- **乌江寨：** 八民族山水大秀、侗族大歌、独竹漂、掌灯仪式、无人机水舞秀、鱼灯巡游、通草堆画非遗、摇橹船夜游。

### 6.3 客流监测
- 乌镇 1–6 月入境 **26.23 万（+67%）**（基线）。
- 古北水镇外籍游客 **+87%**（云雾节期间）。
- 濮院暑期水街 2 倍、水域 +70%，日近万人次。
- 乌江寨平日 **8000+**、周末 **1.4 万**，入住率 **80%–96%**（金台资讯 8/20）。

### 6.4 运营监测
- 策展节奏：乌镇戏剧节首轮售罄、9/5 二轮开票在即，内容稀缺度持续兑现；濮院"折纸计划 + 落日影院"高频轻量内容。
- 票价二消：中高考免票引流、住宿 / 餐饮 / 店铺二消闭环。
- 社区共生：乌镇"空手出游"机场双向转运、古北多语种导视，体现"景区 + 内容 + 社区"可复制逻辑。

**监测结论：** 四大矩阵以"内容策展 + 过夜住宿闭环 + 国际客群运营"为核心；乌镇戏剧节两轮开票机制验证"稀缺内容 + 分批释放"的定价与口碑杠杆。

> 基线 2026-08-03。本期增量与变化如下。

### 7.4 趋势总结与方法论
延续"过夜率总开关 / 内容叙事优于重资产 / 减法比加法值钱 / 本地共建 / 负资产转正 / 票根连接器"框架，本期新增两则可复制要点：
1. **省域夜间经济可成规模引擎**——山东夏夜 718 万 + 4.97 亿证明，省级统筹夜间流量调度能把"夜游"从单点活动做成产业带。
2. **IP + 夜游 + 衍生品闭环**——蓬莱八仙 IP +30~50%，验证内容 IP 须与夜游场景、衍生消费品同频才能放大客单。

## 八、当日趋势点评

1. **山东夏夜数据印证夜间经济成主引擎。** 718 万客流 + 4.97 亿消费，省级统筹夜间流量调度见效。
2. **IP 内容须与夜游、衍生品同频。** 蓬莱八仙 IP +30~50%，提示目的地 IP 运营要落到消费闭环。
3. **海岛目的地扩容靠交通重构（圣淘沙）。** 岛群联动 + 捷运/水上的士，是国内海岛度假区可对标路径。
4. **票根经济周末峰值显著。** 周深济南、萧敬腾运城在周末形成多日消费高峰。
5. **过夜率仍是质量 KPI 总开关。** 乌江寨 80%–96% 入住、临沂二消 200 元+ 共同验证。
6. **内容稀缺度兑现定价杠杆（乌镇戏剧节）。** 首轮售罄、9/5 二轮，分批释放强化稀缺。
