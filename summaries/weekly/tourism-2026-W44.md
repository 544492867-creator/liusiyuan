# 泗月·文旅市场周报（2026-W44 · 10.26–11.01）

> **一句话速览**：长假后第 15–21 个工作日，市场从"节后慢热"切入"冬春换季 + 秋假亲子错峰 + 双 11 囤货 + 万圣夜游收官 + 入境购物游"五窗口并行的确定性获客期；冬春航季 10/25 切换（216 家航司周 11.6 万班、16 条精品入境线 +45.9%）、秋假覆盖百余城（去哪儿 11 月酒店 +50%、亲子游环比翻倍）、入境免签占 77.5% 且 "China Haul" 成全球现象（TikTok 播放超 1.1 亿次），共同把 11 月传统淡季重定义为"亲子错峰 + 南北双向度假 + 入境购物"的结构性增量窗口。

## 一、本周市场回顾

本周（10/26–11/01）是国庆后第三个完整自然周，主线从 W43 的"错峰慢热 × 内容常态化"进一步演进为**"冬春档期启动 + 秋假制度释放 + 入境服务密度升级 + 业态 IP 化"**四线交汇。

### 1.1 政策与行业定调

- **冬春航季 10/25 切换，运力把"南下避寒 / 北上赏雪 / 入境精品线"切成三块**（民航局 / 央视网 / 央视新闻 10/25）：2026/2027 冬春航季至 2027/3/27，216 家航司每周 **11.6 万班**；国内客运周 91454 班、新开 **288 条**国内航线；国际客运通航 **84 国**周 16654 班；**16 条精品入境游航线班量同比 +45.9%**，与新加坡 / 马来西亚等 15 个主要客源国班量 +14.4%；红色 + 文旅成开线理由（武汉—遵义、成都—延安、合肥—延安）。热门小城机票预订量同比 **+2 倍**、候鸟游 **+三成**、阿勒泰 **+60%**。
- **文博场馆节能降碳 235 号文，七类馆纳入绿色转型**（国管局 / 文旅部 / 体育总局 / 国家文物局 / 中国科协 国管节能〔2026〕235 号 10/25）：首次把博物馆、图书馆、文化馆、美术馆、体育馆、科技馆、展览馆整体纳入绿色转型重点；以 2025 年为基数，2030 年单位建筑面积碳排放降 **8.5%**、人均能耗降 **5%**、人均用水降 **3%**，碳排放总量 2030 年前达峰；新建场馆须达绿色建筑二星级以上。
- **《博物馆藏品管理办法》（文旅部令第 15 号）11/01 起施行**（国家文物局 2026-08-28 公布 / 11-01 施行）：原 1986 年办法首次系统修订，明确分类分级管理、全生命周期动态管理、馆长离任藏品清点移交责任制，并专设法律责任章节——文博游与博物馆研学供给获制度底座。
- **"人工智能 + 文旅"14 个应用试点落地**（文旅部办公厅 10/16，新华网 / 经济参考报 10/19）：覆盖辅助创作、公共文化、遗产保护、新业态、服务治理、市场监管 6 大方向，业内解读为从"单点炫技"转向"可感、可用、可管理"的系统能力。
- **文旅部"十五五"规划实施推进会 10/23 召开**（文旅部官网），《旅游强国建设"十五五"规划》首次专章部署旅游公共服务（中国经济导报 10/10）。

- **秋假亲子成 11 月最确定增量**：去哪儿 11 月酒店预订 **+50%**、亲子游订单环比**翻倍**；同程亲子搜索月环比 **+136%**；美团 11 月入住住宿 **+175%**、亲子家庭房 **+109%**、民宿家庭房 **+158%**、亲子景点门票 **+82%**（"1 大 1 小" +215%）（证券时报 / 中国青年报 / 美团 11-01）。
- **"银发 + 年轻"双轮 + 候鸟避寒南下**：途家——55 岁 + 银发旅居最热含西双版纳，长住 7 天 + 订单 + 两成、平均入住 12 天；冬春航季"南下避寒"列为主航道（候鸟 + 三成），版纳列新晋旅居城市（央视财经 10/26）。

## 二、趋势变化

1. **行业标尺进一步"换轨到留消费"**：武当山年会（W43）以 34.63 亿人次 / 3.2 万亿确立首发 / 夜间 / 票根经济为主线，本周**秋假 + 双 11 + 票根经济 + 进博展城联动**把"留消费"从口号落到可量化工具——南京 716 家主体凭票根享景区住宿餐饮三重优惠、重庆非遗"票根全城通用"。
2. **冬春航季让"运力"成为第一获客变量**：16 条精品入境线 +45.9% 确认入境抓手从签证端彻底转向"航班端 + 口岸端"；候鸟 + 三成 / 阿勒泰 +60% / 热门小城机票 +2 倍，目的地竞争从"抢资源"进入"抢档期"。
3. **秋假制度把 11 月重定义为"亲子错峰小黄金周"**：覆盖百余城、分城市错峰释放，去哪儿（+50%/翻倍）与美团（+175%/+109%/+158%）双确认，亲子 + 赏秋 + 银发三线并举。
4. **夜游 IP 化拐点确立**：万圣节"本土 IP 鬼屋"（环球《盗墓笔记》《第五人格》）验证"成人向夜游 + IP 联名 + 沉浸式惊吓空间"是乐园二消新公式，对古北水镇 / 乌镇 / 青城山夜游产品具直接借鉴。
5. **入境游从"China Travel"升级"China Haul"**：免签占 77.5% + 离境退税商店超 1.8 万家 + TikTok 1.1 亿次，购物游成全球现象，瓶颈转为"落地首站服务密度"（多语、支付、退税、邮寄）。
6. **"三转 + 双窗口"战略框架成型**（大秦笔记 10/27）：冰雪 / 避寒 / 银发三转，错峰 + 双 11 囤货双窗口；核心"卖资源→卖场景、靠天→靠运营、卷国内→赚入境"。
