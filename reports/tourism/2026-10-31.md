## 三、消费数据与趋势

1. **总量大盘（官方口径）**。文旅部数据中心测算：国庆 7 天全国国内出游 **8.26 亿人次**、国内出游总花费 **7,383.75 亿元**，按可比口径（日均）同比 2025 年分别 +6.3%、+4.3%（文旅部 2026-10-09 / 经济日报 / 央广网）。
2. **人均账本**。总花费 ÷ 总人次 ≈ 人均 893.8 元（7 天全程），折算单日约 127.7 元/天；日均出游 1.18 亿人次、日均花费约 1,054.8 亿元——「高频、低客单」大众假期模型。
3. **结构三极**。红色旅游渗透率约 40%（推导约 3.30 亿人次）；乡村旅游热度攀升；夜间文旅方面，国家级夜间文旅消费集聚区累计夜间客流 1.07 亿人次（占国内出游 13.0%）、同比 +5.6%；城市公园举办花展、非遗体验等活动 1.1 万场，接待游客超 2.1 亿人次，带动消费超 52 亿元。
4. **错峰窗口量化注脚**。航旅纵横：10/21—11/10 国内航线机票预订量 **超 1,214 万张**（同比基本持平）、出境 / 入境航线机票预订量分别 **超 214 万 / 206 万张、同比 +6% / 约 +7%**（搜狐旅游 10-23）；去哪儿：10/9—10/31 国内机票均价较国庆降超三成，杭州 / 深圳 / 北京 / 上海 / 南京 / 长春等热门目的地单张机票均价较假期便宜近 200 元；央视：北京飞阿勒泰 10-27 裸票 570 元、上海飞鄂尔多斯 10-17 492 元；春秋航空成都进出港阿勒泰 260 元、宁波 260 元、伊宁 300 元、乌鲁木齐 330 元，成都直飞曼谷裸票低至 100 元（四川日报）。
5. **税务视角印证**。国家税务总局增值税发票数据（经消费日报 / 网易等引用）：假期服务消费相关行业日均销售收入同比 +19.5%；旅游游览和娱乐服务 +23.6%（旅行社 +26.2%、游乐园 +41.2%）；民宿服务 +12.8%、经济型连锁酒店 +6.3%；文化艺术服务 +20.9%（群众文体 +28.3%）；悦己型消费崛起（宠物服务 +80.8%、健身休闲 +16.7%、美容 +37.1%）。
6. **平台结构性注脚**。携程：国内度假 8 天及以上行程占比由 2024 年不足 6% 升至今年超 10%；美团：800 公里以上长线游订单 +25%，31% 用户单目的地停留 ≥3 天。县域维度：同程县域旅行产品预订热度 +42%、平均游玩天数 +3.2 天；去哪儿县城酒店预订热度 +35%，九寨沟民宿 +281%、布尔津 +206%。
7. **出境 / 入境双向**。10/1—10/7 内地居民出境 444.4 万人次（同比 +9.3%）；2026 年 10 月中国赴澳航班预订量同比 +19%；去哪儿热门国家酒店预订量同比 +30%。入境方面详见第十节。
8. **趋势判断**。量增快于价增约 2 个百分点，印证「性价比旅游」主流化；低客单 ≠ 低质量，体验型消费替代购物型消费；入境游是高增速、低基数蓝海；错峰 + 双 11 双窗口把传统淡季重定义为消费窗口。

## 五、全球文旅标杆案例观察

### 泰国 · 清迈（Chiang Mai）——古城世界遗产 × 夜市经济 × 中老泰旅游走廊 × 数字游民（持续观察 · 第十六期联动）

- **空间设计**：老城方形护城河格局（约 1.2 km × 1.2 km）完整保留，寺院、民宿、咖啡馆、手作店低密度混居，步行可达；素贴山—因他暖山构成城市绿肺与避暑 / 避寒双季背景；古城内限高与立面管控维持兰纳低矮天际线，与曼谷摩天都市形成差异化。

## 七、国内文旅趋势深度观察

### 7.1 城市微度假（核心趋势 + 代表项目 + 方法论）
- **趋势定义**：1—3 小时出行圈、半日成行、轻决策、过夜导向；国庆后错峰 + 双 11 囤货进一步压低「说走就走」门槛。
- **代表项目**：台州府城「城市微度假生活节」、徐州「经开六小时」、湘潭仰天湖、长沙县星沙；叠加本期万圣节主题乐园夜游（上海迪士尼、北京环球）成为城市微度假夜经济样本。2026-10-31 为周六 + 万圣节，是本周末微度假夜游的情绪最高点。
- **方法论**：「激活存量空间 + 拉动过夜消费」——乐园 / 古村 / 街区用夜场、IP、沉浸式把白天流量转为过夜与二消。

### 7.2 新兴特色小镇与县域（避暑旅居 / 小而美 / 负资产转正 + 案例拆解）
- **避暑 / 避寒旅居**：桐梓九坝夏季长住由 2 万 → 12 万、2025 综合收入 23.2 亿；平坝天龙、绵竹清平（磷矿 → 50 万人次）验证「长住」模型。西双版纳避寒 + 跨境 + 夜游为冬季「候鸟长住」代表，冬春航季（10-31 周六三条跨境线全开）与中老铁路双重利好；广之旅数据显示 10—12 月东南亚错峰黄金窗口，泰国 / 越南 / 老挝 / 尼泊尔 / 斯里兰卡进入旱季，价格较国庆降 20%—40%（搜狐旅游）。
- **小而美 / 负资产转正**：涪陵美心红酒小镇「5 日畅玩票 18.99 / 68 / 98 元」把过路客变过夜客；洞庭渔歌小镇、海城腾鳌 95 浪漫小镇、宜兴阳羡 / 窑湖小镇以「低改造 + 强叙事 + 本地共建」转正。
- **县域爆发量化**：同程县域旅行产品预订热度 +42%、平均游玩天数 +3.2 天；去哪儿县城酒店 +35%；九寨沟民宿 +281%、布尔津 +206%；TOP10 热门景区被小城包揽；25—34 岁占「奔县游」近四成；县域高品质酒店预订热度 +76%、精品民宿 +92%（央广网 / 中国网）。
- **可迁移点**：与白川乡、清迈「社区合力 + 低干预」同源——不靠重资产，靠内容日历与本地参与。

### 7.3 旅游度假区（深度停留 KPI + 代表度假区）
- **KPI 转向**：以「深度游客量 / 过夜率 / 客单价」替代门票客流作为质量判据。
- **代表**：宜兴阳羡生态旅游度假区、仰天湖国际休闲旅游度假区；西双版纳（避寒 + 跨境 + 夜游）本期以冬春航季 78 条航线 + 中老铁路 8,000 万 + 跨境 27 万验证「度假区质量 KPI」样本；青城山—都江堰以康养 + 民宿梯度 + 1 小时通勤验证平季「慢游」模型。

### 7.4 趋势总结与方法论（可迁移到 AI 漫剧）
- **三转 + 双窗口**：冰雪 / 避寒 / 银发三转，错峰 + 双 11 囤货双窗口；夜游 IP 化（万圣节本土 IP 鬼屋）、活态遗产社区共生（白川乡 / 乌镇 / 清迈）。
- **AI 漫剧关联提示**：① 清迈「天灯节古城」、白川乡「雪国童话村」、乌镇「戏剧节 + 水乡」、万圣节「中式惊悚 IP」均可转为漫剧选题库；② 「前置种草 + 后置二消」——漫剧做目的地内容资产，反向导流住宿 / 门票 / 特产二消；③ 低成本内容资产对抗重资产同质化，与特色小镇「低改造 + 强叙事」逻辑一致。

## 十、入境游与「China Haul」专题观察

本期将入境游单列，因 10-20 国家移民管理局发布的三季度数据为当前最具确定性的高增板块，且与「China Haul」购物游形成叠加效应；本期补充商务部 1—8 月离境退税、山东口岸等最新口径。

1. **三季度出入境大盘（官方口径）**。国家移民管理局 10-20 发布：三季度全国查验出入境人员 **1.92 亿人次、同比 +7.9%**（内地居民 9596 万 +7.4%、港澳台居民 7314 万 +6.4%、外国人 2327.2 万 +15.6%）；内地居民出境 **4850.8 万 +7.5%**；外国人入境 **1160.1 万 +15.6%**，其中 **免签入境 899.2 万、占 77.5%、同比 +24.1%**。上半年（1—6 月）全国出入境 **3.69 亿人次**创历史新高（国家移民管理局 / 中国网）。
2. **口岸与城市样本**。北京口岸三季度验放入出境外籍人员 **218 万人次、同比 +30.7%**（中国网 10-21）；上海口岸前三季度 513.8 万外籍（+18.5%）。**山东样本（本期新增）**：2026 上半年山东口岸出入境人员 **352 万余人次**，外国人出入境 **120 万余人次、增幅 28.4%**，免签入境占外籍入境 **85.2%**；同期全省接待入境游客 **103.3 万人次**、入境旅游收入 **7.0 亿美元**，同比分别 **+44.2% / +43.3%**；青岛上半年直接入境游客 **44.3 万人次、+56.2%**，截至 10-8 青岛机场口岸入境外籍突破 **50 万人次、+30%**、免签占 81%（中国日报网山东 10-26）。新皇岗口岸 10-12 开通、截至 10-19 查验 88.6 万人次、车 7.4 万辆，深港通关时间由 30 分缩至 5 分。
3. **「China Haul」购物游崛起（最新口径）**。海外社交平台「China Haul」相关视频 TikTok 播放量 **超 1.1 亿次**；商务部：1—8 月全国离境退税销售额 **同比 +60%**、办理离境退税人数 **同比 +300%**；目前全国离境退税商店 **超 18,000 家、较 2024 年底 +400%**（商务部新闻发布会 10-23，经 iChongqing 转引）；前 7 月海外人员在华消费规模 **2636 亿元（约 390 亿美元）、同比 +27.8%**（LinkedTours 汇总）。购物清单从茶叶丝绸升级为折叠屏手机、AI 眼镜、无人机、智能手环、国潮箱包、潮玩盲盒、非遗文创、中医药膳。1—8 月外国人出入境 **6129 万人次、+19.5%**，其中免签 **2372 万、+26.8%**（深圳报道）。

5. **消费逻辑与启示**。外国游客核心动机从「猎奇购买」转向「价值认同」，反向代购体现对中国品牌信任票；「养生 + 旅游 + 购物」跨境消费模式形成（草本香皂、艾灸、药膳入清单）；智能工厂科技游成入境新热点。对城市启示：离境退税、多语种标识、外卡支付、国际邮寄、极速定制等配套完善，正把「空箱而来、满载而归」做成国际化消费场景，商圈与街巷承接确定性红利。
