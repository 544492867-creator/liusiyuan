### 1. 普惠养老服务价格机制文件持续落地（国家层面核心制度增量）
- **文件**：国家发改委、民政部、国家卫健委《关于进一步完善价格形成机制 推动普惠养老服务提质扩面的指导意见》（**发改价格〔2026〕1476号**），2026-10-12 印发，央视网 10-17 作专题解读，中国政府网 10-16 全文公开。
- **核心内容**：首次在国家层面将养老机构分为三类并差异化定价——兜底保障型（特困 / 经济困难失能老人公办机构，基本服务政府指导价、特困免费收住）、普惠支持型（公建公营 / 公建民营社会办及获场地减免或建设运营补贴的社会办机构，基本服务政府指导价或参考区间，具体范围由省级民政制定认定办法、地级及以上民政认定并发布名单）、完全市场型（市场调节价、鼓励优质优价）。建立目录清单管理（所有收费进清单、清单之外一律不得收费）、收费动态评估（周期 ≤3 年），总体按「补偿成本、合理盈利」原则。
- **配套资金**：发挥中央预算内投资、超长期特别国债、地方政府专项债券带动作用；用水用电用气用热按居民生活类价格执行；用好地方留成彩票公益金强化养老护理员队伍。

## 五、全球养老标杆案例观察：**丹麦「原居安老 / Aging in Place」—— 不建养老院，把服务送上门**

> 轮换说明：上期（10-31）跟踪英国 Extra Care Housing / 集成退休社区（IRC）；上上期（10-30）荷兰 De Hogeweyk 失智长者村；10-29 日本地域包括照护系统；10-28 新加坡乐龄 Age Well SG；10-27 德国多代屋。本期切换至**丹麦「原居安老（Aging in Place / 原宅养老）」**，呼应国内「居家社区机构协调、原居安老、社区嵌入式、物业 + 养老、长护险居家化、把服务送上门」主线，以及青岛「五床联动 + 社区融合」方向。丹麦作为全球「去机构化 / 原居安老」理念发源地与高福利标杆，对国内社区嵌入式养老、老旧小区适老化、居家护理上门、长护险支付向居家倾斜有直接借鉴价值。
> **来源说明**：丹麦数据来自山东行政学院学报《丹麦"原宅养老"社区养老服务的特色经验与启示》（2025 年第 4 期）、颐联社《丹麦的"原居安老"》（2026-10 微信）、丹麦国家统计局（Danmarks Statistik）2024-07 数据、NIA《Caring for an Ageing Denmark》报告（2026-10）。涉及具体成本对比、满意度排名为国际比较估算或机构自评，均标注「待核实 / 估算」。

### 1. 概念与定位：1987 年立法停止新建养老院
- 丹麦 1987 年通过立法**停止新建养老护理院**（1988 年立法暂缓对各地养老院建设提供资金支持），集中资源发展社区养老与居家护理；1987 年《原宅养老福利制度》《老年人及丧失劳动能力者住房法案》确立「原地养老」原则。
- 核心理念「Aging in Place（原居安老 / 原宅养老）」：老年人在自己熟悉的家庭或社区环境中安度晚年，养老场景从家庭拓展到社区，地方政府支持、社区主要负责提供服务；本质是通过政策引导、社区服务和技术创新，让老人维持有尊严自主的生活，养老不离家，延缓或避免进入机构。
- 丹麦被称为社会民主主义型福利国家，建立「从摇篮到坟墓」福利体系；据丹麦国家统计局 2024-07 数据，**人口约 597 万**，**60+ 近 160 万**占 **27%**，**65+ 约 123 万**占 **21%**，百岁以上 1266 人；老龄化程度与我国相近（我国 60+ 占 23.0%），但财政福利传统迥异。
- 来源：山东行政学院学报 2025-4；颐联社 2026-10；Danmarks Statistik 2024-07

### 2. 四大支柱：住房适老化 + 24 小时居家护理 + 社区日间照料 + 预防性健康管理
- **第一支柱——住房适老化改造**：老人申请、政府评估后出资改造（装扶手、防滑、拓宽门廊）；丹麦适老化改造强制标准——所有新建住宅预留无障碍设计，旧房改造可申请最高 **10 万丹麦克朗**补贴；资助安装语音助手、跌倒监测传感器等物联网设备，费用由市政承担；实施「终身住宅」计划，鼓励可灵活改造的多代共居社区。
- **第二支柱——24 小时居家护理**：护士、护工定期上门（助浴、换药、康复训练、临终关怀），护理人员可在 **30 分钟内**到达；据 NIA 2026 报告，2024 年丹麦居家护理日均约 **70%**  recipients 被分配少于 2 小时护理、**10.77%** 为 2–4 小时、**10.36%** 为 4–8 小时、**4.85%** 为 8–12 小时、**3.85%** 为 12–20 小时；服务按需求个性化评估。
- **第三支柱——社区日间照料中心**：白天老人来吃饭、活动、康复训练、社交，晚上回家；每个市镇至少设 1 个 24 小时应急日托中心；社区设老年人服务中心提供健康咨询、交通接驳、社交活动。
- **第四支柱——预防性健康管理**：定期家访评估身体变化，及早干预；**65 岁**起有健康问题者政府安排「预防性家访」，**75 岁**起所有老人定期「安全家访」排查隐患（北京青年报 2015 报道引丹麦实践）。
- 来源：颐联社 2026-10；NIA《Caring for an Ageing Denmark》2026-10；山东行政学院学报 2025-4；ynet.com 2015-10-21

### 3. 制度演进与 2024《老年法》（Ældreloven）改革
- 丹麦保障法演进：1891 非缴费型养老金 → 1932《老年人援助法》→ 1933《社会福利法典》→ 1959《国民养老保险法》→ 1976《社会服务法》（首次明确地方政府提供居家护理、送餐）→ 1987 原宅养老立法 → 1997《老年人保障法》确立「原地养老」→ 2007《长期护理改革法案》（分级护理 + 护理补贴）→ 2012《跨代共居法》+ 家庭护理委员会 → 2022《老年人权益与自主法案》（赋予老人护理计划决策权、禁止强制入住机构）→ 2023《护理服务数字化法案》（远程医疗、智能监测）。
- **2024《老年法》关键转向——「整体护理（helhedspleje）」**：将个人护理、实务协助、基础康复整合为单一协调护理路径，而非割裂的单项服务；强调连续性、人际关系、按需灵活，不再僵化按时间分配；推行**固定护理团队（faste teams）**，减少进入老人家中的不同员工数量、增强信任；强化数字与福利技术（个人应急呼叫按钮、自动药盒、远程监测）使用，基于功能评估授予。
- 来源：山东行政学院学报 2025-4；NIA《Caring for an Ageing Denmark》2026-10

### 4. 成本账与成效（含估算标注）
- **成本对比（估算）**：颐联社引国际比较估算称，丹麦「原居安老」人均养老支出比机构模式低约 **1/4**（省下机构硬件与后勤，把钱花在适老化改造与预防性健康上）；该对比为国际比较估算，标注「待核实」。
- **财政体量**：丹麦社会总支出占 GDP **32.1%**，其中老年人长期护理支出占 GDP **4.8%**（世界前列）；2005 年长期护理投入 40.55 亿欧元、占 GDP 1.95%、99% 用于扶持养老行业；2020 年财政赤字 1600 亿丹麦克朗（占 GDP 7%，35 年最高）——高福利下财政可持续性承压（山东行政学院学报）。
- **意愿数据**：2007 年欧盟国家 65+ 接受机构照料者平均仅 **3%**；丹麦仅 **4%** 老人愿自费购买市政保障之外的私人养老服务；近九成老人选择独居或与配偶居（丹麦「去家庭化」过度依赖公共福利亦引发公平与可持续讨论，标注「待核实 / 学界观点」）。
- 来源：颐联社 2026-10；山东行政学院学报 2025-4；ynet.com 2015-10-21

### 5. 镜鉴与难点
- **可借鉴**：①「原居安老」理念与我国社区嵌入式、老旧小区适老化、物业 + 养老方向一致；②把「居家护理」作为长护险支付主场景——我国长护险应让老人在家就能得到护理，而非必须住机构才报销；③社区日间照料从「做样子」变为真实服务网络（上海「长者照护之家」「综合为老服务中心」方向正确但覆盖率差距大）；④适老化改造从老人自费变公共服务，政府补贴 + 社区统一推进可显著提升接受度；⑤2024《老年法》「整体护理 + 固定团队 + 数字赋能」对我国长护经办有参考价值。
- **难点 / 不可照搬**：① 丹麦「从摇篮到坟墓」高税收（社会支出占 GDP 32.1%）支撑，我国属地财政差异大、难以全盘复制；② 人口基数与福利传统不同，近九成独居、公共福利替代家庭责任，与我国「孝亲家庭」文化冲突；③ 我国「9073」格局下机构与社区边界、产权关系不同，直接复制「不建养老院」不可行；④ 护理人才配比、质量监管成本仍需本土化；⑤ 丹麦成本对比、满意度排名为估算 / 自评，引用时标注「待核实」。
- 来源综合：山东行政学院学报 2025-4；颐联社 2026-10；NIA 2026-10；ynet.com 2015-10-21

### 6. 本土化启示
- 对应国内「社区嵌入式养老机构 + 家庭养老床位 + 物业 + 养老 + 五床联动 + 长护险居家化」组合：学习丹麦「服务送上门、老人自决、社区融合、预防优先、数字赋能」内核，以「小区闲置资源改微型养老院 + 上门照护 + 适老化租赁 + 居家护理纳入长护支付」替代重型机构；把社区日间照料中心、长者食堂、康复站点做成真实服务网络而非展示；推动长护险待遇向居家、社区护理倾斜（参照中山 / 厦门居家支付 80%/60% 高于机构的设定）。
- 来源综合：颐联社 2026-10；康养每日观察 #6（中山 / 厦门支付结构）

## 八、青岛康养地产政策专项（第 50 期）

> 基线（2026-07-23 发布，全国首个城市级康养地产系统性支持政策「11 条」）：健康服务中心「计容不计价」、出让款分期（最迟 1 年、付 50% 承诺 6 个月开工可进场）、「正负零」预售、「商改住」转型（自持 ≥10 年）、再贷款 1.25% / 最长 3 年、保险资金 REITs 等。本期追踪新动态（敬老月收官、银发消费季延续至 12 月、一类事 105 项落地、康养产业博览会 450 余家企业）。

### 1. 政策原文摘要（本期主线：服务集成 + 消费促进 + 金融赋能 + 产业博览ification）
- **来青旅居康养「一类事」集成化改革（2026-10-10 发布）**：市行政审批局联合文旅 / 民政 / 公安 / 卫健 / 医保等 **22 部门**，围绕「食住行、游学乐、医康养」三场景，首批归集服务事项 **105 项**，「三个一」架构（一张清单聚需求 / 一套阵地就近办 / 一个矩阵广知晓）；选取崂山 / 西海岸 / 胶州试点，2026 年底前建不少于 3 处标准化样板站点（旅居服务微站）。
- **2026-10-14 青岛「敬老月」暨银发消费季**（民政局 / 商务局 / 文旅局 / 人行青岛市分行联合）：活动 10 月持续至 12 月（敬老月 10-01 至 10-31，征集 **48 项**特色活动），贯通「吃住行医康养游学乐」全消费场景。**新增亮点（本期）**：指导 **45 家**养老机构推出「银龄试住周」，通过低价试住、免费短期体验让老人实地了解服务环境；安排「孝心陪购员」一对一服务、工作日上午「银发时段」错峰折扣。惠老购物端——全省率先新增 **8 类**地方自主补贴品类（助行外骨骼机器人、助听器等适老产品享 **15%** 补贴）；市级财政投放 **5000 万元**线上消费券（京东 / 抖音 / 淘天三大平台）。文旅端——依托「一张票根游青岛」小程序联动 **900 余家**（敬老月报道称 850 余家，口径微差标注）合作商户；统筹推出 **8 款**康养旅居产品、**10 条**银发旅居康养精品线路（含「八大关颐居」「藏马山森氧疗愈」「即墨温泉疗养」及温泉疗愈·海洋暖养等）。
- **三年行动方案**（2025—2027，13 部门）：编制《青岛市康养旅居保障清单》《青岛市康养旅居地图》；组建康养旅居产业共同体（20 余家企业）；联动文旅打造 **18 个**旅居康养产品；与 20 余城市达成合作。
- **健康养老产业高质量发展行动方案**（20 部门，2026-02-03）：持续推进「五床联动」；到 2027 年培育 **10 个以上**健康养老服务品牌；支持智慧养老院、社区「虚拟养老院」、物业 + 养老、家政养老。
- **金融赋能（人行青岛市分行）**：截至 8 月末，全市银行机构运用各类结构性货币政策工具累计发放健康与养老产业贷款 **140.3 亿元**，加权平均利率 **2.68%**（较同期企业贷款利率低 0.57pp）；梳理服务消费与养老领域企业（项目）清单超 **1700 个**，年内累计发放贷款 **54.6 亿元**；引导金融机构推出「养老机构贷」「诊易融」等信贷产品 **16 项**；现场发布《青岛市养老产业政策与金融产品汇编》涵盖 38 项政策。

### 2. 核心条款解读

### 3. 影响评估
- **对青岛本地项目**：泰康之家·海琴府、君凯养老等高品质机构落地；「五床联动」打通医养，降低机构医疗配套成本、提升入住信心；20 个健康养老品牌目标牵引供给提质；银发消费季 5000 万消费券 + 8 类补贴直接拉动适老产品本地消费；140.3 亿健康与养老产业贷款降低机构融资成本（利率 2.68%）；45 家机构「银龄试住周」降低决策门槛、转化潜在客群；450 余家展商 + 9600㎡训练验证中心强化「机器人进真实场景」底座。

- **落地挑战**：105 项 + 47 项 + 8 类补贴从清单到「门口办 / 指尖核销」需三级阵地（政务中心专区 + 景区 / 机构微站 + 流动队）真正铺开；跨部门数据打通与「政策明白人」培训是关键瓶颈。
