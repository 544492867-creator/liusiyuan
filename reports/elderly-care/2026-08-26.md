## 一、政策动态（国家 / 地方扶持政策、养老产业新规）

### 1.1 头号政策 · 国家医保局印发《关于做好长期护理保险支付管理工作的指导意见》（医保发〔2026〕19号，2026-08-26 发布）
今日（8/26）国家医保局正式发布长护险支付管理专项指导意见，对支付范围、支付方式、支付标准、基金监管作出全国统一规范，是长护险从「试点探索」迈向「制度定型」的关键一步。核心条款（来源：国家医保局官网 2026-08-26 政策解读、央视新闻 2026-08-26）：

- **支付范围**：基金可报销三类费用——失能等级评定机构的失能评估费、定点养老护理机构提供的长期照护服务费、第三方机构经办管理费。失能评估费由基金与个人共担（防过度申请）；首次评估合格及按规定定期复查费用予以报销。超出国家长护险服务清单的项目个人自费；基本医保与长护险原则上**不重复报销**。
- **支付方式**：评估服务主要按人次付费；护理服务主要按服务时长计费——**居家护理按小时、机构护理按住院天数、社区护理按实际服务内容**；后续将探索智能照护设备、辅助器具「定额打包或按项目付费」。
- **支付标准**：各地结合基金财力、老人基本照护需求、当地护理行业收费水平合理确定并动态调整；按当地经济水平、平均工资、护理人员专业等级分档；**参保人年度长护险基金最高报销额度不超过当地上一年城乡居民人均可支配收入的 50%**；统筹鼓励居家与社区护理。
- **基金监管**：优化结算、智能审核、加快打款；对评估通过率畸高畸低、护理未按计划执行、社会力量经办不合规者按比扣除直至拒付；**长护险资金不得由第三方社会力量代管代拨**；纳入常态化检查（飞行检查、日常巡查、智能监控），研究建立信用黑名单。

> 影响判读：该文件首次对「居家 / 社区 / 机构」三类护理的支付单元与上限作出统一规则，直接强化「居家和社区优先」导向，与青岛「健康服务中心 + 居家上门」模式、全国「五床联动」支付确定性高度契合（详见八）。

### 1.2 《全民医疗保障"十五五"规划》落地（2026-08-19 发布）
国家医保局 8/19 公布《全民医疗保障"十五五"规划》，明确 2030 年全面建成多层次医保体系，**"十五五"期间全面建立长期护理保险制度**；从市地级统筹起步，有条件省份探索省级统筹；健全全国统一失能等级评估标准、推动**评估结果全国互认**；探索家庭医生参与失能评估；动态完善统一长护险服务项目目录；推动长期照护师职业化（来源：中国新闻网 2026-08-19、界面新闻 2026-08-23 深度解读）。

### 1.3 长护险扩面进展（维持前期观察）
- 截至 2026-08，长护险**参保规模 3.2 亿人**（试点扩展至 92 个地区）；2026 年 1–5 月 **137 万人享受待遇**（来源：国家医保局 8/13 通报，维持）。
- 省域建制收口期持续：17 省已出方案（福建 / 河南 / 新疆兵团 / 重庆 / 广西 / 江西 / 黑龙江等），费率普遍趋近 0.3%，2028 年前后集中全覆盖（前期基线维持）。

### 1.4 银发消费 / 适老化政策
- 《扩大消费"十五五"规划》（国函〔2026〕66号）将「扩大养老消费」置于首位，首提银发消费专区、养老服务师、银发产品认证（前期基线维持）。
- 居家适老化改造纳入消费品以旧换新补贴范围（前期维持）；多省市推出银发消费专项支持（前期维持）。

## 五、全球养老标杆案例观察 · 瑞典（Sweden）居家原居安老体系

> 本期选取瑞典作为海外标杆拆解。瑞典是「原居安老（Ageing in Place）」的制度源头之一，与青岛「全龄健康社区」、万宁阿那亚「不离家 / 不离社区」理念形成强对照。

### 5.1 运营与制度底座
- **1992 年 Ädelreformen（埃德尔改革）**：将医疗与福利服务从中央政府下放到 **290 个市镇（kommun）**，大型养老机构逐步萎缩，确立「在自己家中养老」为国家战略。市镇拥有预算权与执行权，按本地实际构建服务体系（来源：Monthly Chosun 2026 韩国养老专题、瑞典官方 Sweden.se）。
- **法律框架**：《社会服务法》（Socialtjänstlagen）规定老人有权获得社会帮助；市级统筹、税收筹资，中央政府设「老龄与社会安全部（Äldre- och Socialförsäkringsdepartementet）」定方向与监督（部长 Anna Tenje 2024-10 访韩谈 AI 与尊严平衡）。
- **约 95% 老人选择居家养老**（来源：山东省养老网国际经验 2026-03）；65 岁以上占总人口约 20%，2040 年预计升至 23%（来源：Sweden.se）。

### 5.2 服务供给与支付
- **需求评估 + 个性化服务**：申请后经「照护经理（care manager）」评估，按需提供洗澡 / 穿衣 / 购物 / 清洁 / 用餐配送 / 交通 / 住宅适老化改造等；特殊情形转入「特别住房（special housing）」即护理型住宅。
- **自付封顶**：家居帮助、日间活动等月度自付上限 **SEK 2,660（约人民币 1,800 元）**，超出由税收补贴；公私并存，老人可自选公 / 私运营方。
- **老年住房（senior housing）**：面向 55+（部分 70+）普通住宅，无障碍优先，新建或改造而成。

### 5.3 智慧硬件与医养结合
- 居家优先依赖**用药机器人、应急警报、远程医疗**；国家卫生福利委员会调查显示，**近 90% 居家老人感到安全、超 80% 对服务满意**（来源：KCL 博客 / 欧盟委员会国别研究）。
- 医疗改革将部分医生权限下放护士、护理助理，扩大服务覆盖；前期老人照护后期老人（pre-frail 照护 frail）项目扩充人力池。

### 5.4 投融资与政策配套
- 福利税筹资为主，市镇财政自治；长期护理属普遍福利，非商业保险主导。
- 养老金改革将退休年龄与预期寿命挂钩，并设反年龄歧视保护，鼓励延后退出劳动力。

### 5.5 本土化改造难点（镜鉴中国）
1. **高税收不可复制**：瑞典模式依赖高税率市镇财政，中国城市难以照搬，需以「保险 + 自付 + 商保」组合替代。
2. **区域不均**：市镇自治致服务标准与质量地区差异，对应中国长护险「省级 / 市级统筹」的公平挑战。
3. **公 / 私责任分割协调难**：医疗归大区、照护归市镇，新冠暴露协调缝隙与人力短缺——对应中国「五床联动」需打通卫健 / 民政 / 医保。
4. **数字鸿沟**：76 岁以上 2020 年上网率 73%（十年前仅 23%），但数字素养落差仍存——提示适老化内容须「大字 / 高对比 / 慢节奏 / 强陪伴」（见七）。
5. **适老住房供给不足**：新建住宅中「senior housing」占比有限，限制原居安老落地——与中国康养地产「存量商住转康养」思路可互鉴。

> 对青岛 / 万宁的镜鉴：瑞典证明「居家 + 社区」是成本更低、满意度更高的主流路径；青岛「健康服务中心自持 + 居家上门」、万宁阿那亚「全龄健康 + 不离社区」与之同构，但须以**支付确定性（长护险 / 商保）**与**跨部门协调**补瑞典式短板。

## 七、银发经济趋势与客群观察

### 7.1 客群趋势变化
- **60 后「新老人」悦己消费**：从「省吃俭用」转向「为自己花钱」，21% 为品质引领群体、74% 线上化（前期基线）；55–65 岁新银发消费增速超 60%（本期核实，见三）。
- **70 后准老年提前规划**：41–50 岁职场人群已成消费主力（前期基线），「未老先养」前置消费明显——青岛数据显示 2025 年康养消费中 30 岁以下参与者占 14.3%，全龄前置趋势确立。
- **80+ 高龄刚需升级**：照护、康复、认知症干预需求刚性上升；护理员缺口 550 万、流失率高，倒逼机器人补位（见四）。
- **性别 / 城乡 / 区域差异**：女性占银发消费约 74%（前期基线）；城乡与区域支付能力落差显著，县域养老服务提升计划（商务部等 9 部门）成新抓手。

### 7.2 经济发展趋势变化
- **细分赛道增速分化**：老年旅游 / 体育健康服务 2026H1 +26% / +24%；上海银发文旅 +7 倍；智能可穿戴 +32.6%；适老化产品供给却 <0.1%（见三）——「有效供给稀缺」是核心矛盾。
- **支付端演进**：长护险 3.2 亿参保、137 万人享待遇；今日支付管理指导意见统一支付单元（居家按小时 / 机构按天 / 社区按内容）、上限不超上年城乡人均可支配 50%（见一）；消费券（新疆）、商保（国寿西藏年金）多线并进。
- **科技赋能**：机器人从赛事走入机构日常（武汉 / 上海 / 深圳）；AI 健康助手（蚂蚁阿福 1.3 亿用户、老年 25%）渗透加速。

### 7.3 特色内容观察（与 AI 漫剧选题关联）
- **银发网红 / KOL 崛起**：抖音「爷爷奶奶」相关视频播放 **106 亿次**；60+ 粉丝超 400 万老年网红 >20 位；90 岁梅英阿嬷粉丝中 25–34 岁占 46%（来源：今日头条 2026-08-08）。
- **老年大学「赛博祖辈」**：短视频剪辑 / AI / 无人机课程爆满，老人反向输出内容。
- **「银龄剧场」微短剧范式（强关联 AI 漫剧）**：湖州蜀山养护院 95 后护士带九旬老人拍《蜀山情报站》，全网播放破 500 万、160+ 条，家属咨询涨 3 倍、7 家机构取经（来源：央视网 / 新华社 2026-08-23、搜狐 2026-08）。本质 =「微短剧 + 真实养老日常 + 代际共创」，验证了「强陪伴感 + 慢节奏 + 真实松弛」的内容公式。
- **适老化内容设计原则**：大字、高对比、慢节奏、强陪伴感（与瑞典数字鸿沟镜鉴呼应）；「反年龄叙事」「电子祖辈」「科技 + 情感双驱动」为爆款内核。
- **AI 漫剧关联提示**：养老院的「银龄剧场」证明「老人当主角、轻剧本、方言反差、治愈向」可低成本高产；AI 漫剧可复用该叙事引擎，将养老真实故事转译为动画短剧，兼具情感价值与适老化触达。

## 八、青岛康养地产政策专项追踪（新增 2026-08-11 起）

### 8.1 政策基线（维持）
- 《青岛市支持康养地产高质量发展若干政策措施》（11 条，2026-07-06 印发、7-23 发布），**全国首个城市级康养地产系统性支持政策**；配套《康养地产项目认定标准（试行）》划分五类（旅居 / 养老护理 / 理疗康复 / 健康养生 / 复合）。
- 核心条款：健康服务中心 **650㎡/千人**（>1000 套住宅最小 3500㎡、其他最小 1000㎡）；**计容不计价**（降土地成本）；土地款可分期≤1 年、缴 50% 并承诺 6 个月开工即可提前交地；支持 2024-03-31 前存量商住用地转康养；再贷款（最低 1.25%）、REITs / 保险资金入局。
- 配套：市南区《打造"中国康湾"特色承载区行动方案》（40 项）、"中国康湾"三年行动（2027 破 1000 亿 / 2026 年 15 项目 87 亿 / 险企 14 亿）、市民政局改革（医养结合五床联动）、曾赞荣《学习时报》署名文章。

### 8.2 本期动态（2026-08-26）
- **本期（8/26）无青岛市级新康养地产政策文件发布** → 明确标注「无公开新增动态，维持前期观察」。
- **今日国家层面强关联**：国家医保局《长护险支付管理指导意见》（见一）明确「居家护理按小时、机构按住院天数、社区按内容」「鼓励居家和社区护理、上限不超上年城乡人均可支配 50%」，**为青岛「健康服务中心自持 + 居家上门」运营端提供支付确定性**，与青岛 8/15 深化的「五床联动」形成上下呼应。

### 8.3 实施进展追踪（维持 + 本期核实）
- 中国康湾：集中推进 **15 个重点康养项目、总投资超 87 亿**；泰康 / 国寿 / 太保等险企在青康养投资累计超 14 亿；康复大学等 30 余家高端平台布局（来源：界面新闻 2026-08）。
- 已落地 3 个康养地产项目（龙湖 / 海信璟悦 / 君一，前期基线维持）；机器人训练验证中心 45 企 217 台套（前期维持）。
- 养老消费：青岛 298 家机构、9.8 万家庭床位、17.8 万消费券（前期基线维持）。

### 8.4 影响评估
- **对青岛本地项目**：支付管理指导意见强化「居家 / 社区护理」报销预期，利好健康服务中心持续运营与自持现金流；存量商住转康养的「商改住去化」仍取决于医疗配套与运营能力。
- **对万宁阿那亚等异地项目（4 项借鉴）**：① 全龄健康定位（适老不唯老）；② 10 年运营承诺（对抗快周转）；③ REITs / 保险资金入局（重资产退出）；④ 医疗可携 / 长周期支付（对接长护险全国互认趋势）。
- **落地挑战（4 项）**：① 医疗配套可达性；② 自持运营现金流压力；③ 护理人才缺口（全国 950 万级）；④ 商改住去化周期。
- **全国示范意义**：青岛 11 条已被第一财经等援引为全国参照系，吉林 / 云南 / 海南 / 烟台等竞逐「抢老人」；今日长护险支付规则全国统一，将进一步放大青岛「制度 + 场景」先发优势。

## 当日趋势点评

1. **长护险「支付规则全国统一」是本日最大变量**：医保发〔2026〕19 号首次把居家 / 社区 / 机构护理的支付单元与上限钉死，并明确「不得第三方代管代拨 + 信用黑名单」。对行业意味着——长护险从「报销工具」升级为「服务市场指挥棒」，居家和社区护理获确定性溢价，直接利好青岛健康服务中心、万宁阿那亚全包式健康会员等「运营型」模式。
