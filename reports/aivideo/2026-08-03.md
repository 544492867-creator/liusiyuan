# 泗月 · 漫剧/AI视频制作 日报（2026-08-03 周一）

> 今日行业关键情报：① Seedance 2.5（7/31 上线）进入首批实测期，"30 秒直出 + 角色一致性"成核心测评维度，即梦等 C 端可用；② DataEye：AI 漫剧 6 月上新 3.77 万部、播放 1557.8 亿，男性 18–34 岁为主力，玄幻 / 修仙 / 都市脑洞 / 逆袭最吃香；③ 行业"审美大考"延续——《被裁掉的女孩》AI 演员霸榜印证"人物情感真实 > 技术炫技"。**结论：拼审美判断与叙事真诚，不拼 AI 含量。**

## 【当日创作选题】

**素材采集来源联动**：今日三平台热点（世界杯余热、立秋倒计时、暑期过半）、访谈金句、行业洞察（AI 漫剧男性向脑洞主导）。剔除项：世界杯赛事版权画面（侵权风险）、立秋泛文案（无增量）、纯文字方法论（不适配视觉）。

1. **《球迷的 30 天》治愈漫剧**（1 集 / 50s）— 灵感源自世界杯余热，做"普通球迷情绪纪录"原创化改编，不搬运赛事画面
2. **《立秋前的最后一碗西瓜》节点治愈短片**（1 集 / 15s）— 卡位 #立秋# 节点，本周启动、8/7 达峰
3. **《能力重定价》都市脑洞漫剧**（1 集 / 60s）— 改编自"35 岁职场"热议，正面迎击男性 / 逆袭 / 脑洞主力客群

## 【适配风格】

1. 选题 1：**治愈 / 情感**（球迷烟火、微光叙事、群体共鸣）
2. 选题 2：**治愈 / 节点**（节气仪式感、轻励志、强时效）
3. 选题 3：**干货 / 认知观点**（都市脑洞外壳 + 职场认知内核，男性向）

## 【完整短脚本】

**选题 1《球迷的 30 天》**（50s，治愈漫剧）
- **人物**：老陈，42 岁，普通上班族，二十年球迷；妻子（不理解但包容）、儿子（偶尔陪看）
- **剧情框架**：深夜看球被妻子催睡→决赛夜偷偷在客厅看到凌晨→球队赢球他独自握拳落泪→次日顶着黑眼圈上班，同事问"昨晚看了吗"他笑→结尾定格：手机壳背后贴着一张泛黄球星卡
- **台词**（旁白，温和带笑）：「二十年了，家人总说他看的是热闹。只有他自己知道——那是他唯一不被生活叫停的 90 分钟。」
- **画面**：暖色调生活流，客厅暖光、电视蓝光映在脸上、手机壳特写。无冲突、纯情绪。
- **评论区钩子**：「你看了多少年球了？」
- **合规**：不出现任何真实球队 / 球员 / 赛事画面，用"那支穿红色球衣的队"隐喻。

**选题 2《立秋前的最后一碗西瓜》**（15s，节点卡点短片）
- **人物**：无具体人物，第一人称视角
- **剧情框架**：3 组画面——冰箱里最后半个西瓜→勺子挖中间最甜的那口→窗外蝉鸣渐弱、风变凉→字幕「夏天要走了，但甜还在」
- **台词**（字幕卡点）：「立秋前最后一口西瓜 / 把夏天含在嘴里 / #立秋」
- **画面**：真实感生活流 AI 图生视频，光线由午后的亮转黄昏的柔，BGM 用吉他轻拨卡点。
- **⚡ 时效纪律**：本周内发布，8/7 当日达峰，轻制作快产出，总工时 ≤2 小时。

**选题 3《能力重定价》**（60s，都市脑洞漫剧）
- **人物**：林哥，36 岁，被裁员后发现自己"技能市场价格"远低于预期；神秘 HR 系统弹出「能力重定价中…」
- **剧情框架**：林哥收到裁撤通知→打开求职 App 发现自己的"估值"只有巅峰期三成→他翻出压箱底的能力清单（带团队、谈客户、救火）逐一"重新上架"→三个月后估值回升，但他说"这次我给自己定价"→彩蛋：App 小字「市场价 ≠ 你的价值」
- **台词**：「被裁员那天才知道——公司给的 title，从来不是你的价格。」「重新定价的过程很痛，但不定价更痛。」
- **画面**：2D 都市漫剧风，求职 App 界面做成"股票 K 线"隐喻，低迷灰调 → 回升暖调，用色彩讲情绪。
- **改编声明**：认知内核来自"35 岁职场"公共讨论，转译为剧情不直接引用真人。

## 【AI 画面制作参数参考】

- **模型选择**：
  - **首选：Seedance 2.5（7/31 上线，即梦端）**——30s 单段直出减少拼接缝；支持 50 个全模态参考素材，上传角色三视图锁脸，**重点解决「配角撞脸」行业硬伤**（选题 1 老陈、选题 3 林哥均需锁脸）
  - 备选：可灵 AI（图生视频，选题 2 生活流）、Vidu / 即梦图生视频兜底
  - 成本：Seedance API 720p 约 0.99 元/秒，C 端会员更划算，单条 60s 成片预算 ≤50 元
- **风格定位**：选题 1 暖色生活流（参考是枝裕和家庭感）；选题 2 真实系生活流；选题 3 现代 2D 都市漫剧（灰→暖双色板）
- **分镜建议**：选题 1 共 5 镜（夜 / 屏 / 泪 / 班 / 卡），8–12s/镜；选题 2 共 3 镜快闪，4–5s/镜；选题 3 共 7 镜，低谷 3 镜灰调等长、回升 4 镜渐暖
- **节奏与声音**：选题 1 环境音（电视声、蝉鸣）为主；选题 2 吉他轻拨卡点；选题 3 前段白噪音后段鼓点。配音：Seed Audio 中文情感音，剪映智能配音兜底
- **工具链**：DeepSeek 写本细化 → 即梦（Seedance 2.5）/ 可灵生成 → 剪映剪辑 + 字幕 → 统一片尾水印

## 【成品归档 & 迭代优化方向】

**归档**
- 今日 3 套脚本 + 分镜参数归档至 `reports/aivideo/` 素材库；赛道标签：治愈漫剧 × 1、节点短片 × 1、脑洞认知漫剧 × 1
- 可二次改编：选题 1 可系列化为《普通人的 30 天》（球迷 / 钓友 / 票友，每集一爱好一人物）；选题 3 可延展「重定价系列」（技能 / 关系 / 自我），瞄准男性脑洞赛道栏目化
- 昨日《人生难度选择器》与今日《能力重定价》同属「自我认知」母题，确认沉淀为个人创作母题库支柱

**制作难点记录**
- 角色一致性仍是生死线：用参考素材锁脸，配角也不能省（呼应《桃花潭记》撞脸翻车）
- 节点类内容（选题 2）时效以天计，须建立「2 小时轻量出片」快反模板，与重制作漫剧双轨并行

**迭代优化方向（基于 Seedance 2.5 首批实测）**
1. **供给爆炸下突围逻辑变了**：月上新 3.77 万部，「做出来」无价值，「审美 + 真诚叙事」是唯一过滤器——《被裁掉的女孩》赢在人物真实不在技术
2. **客群校准**：AI 漫剧主力 18–34 岁男性（超六成），治愈向是蓝海但天花板低；策略：脑洞 / 逆袭（选题 3 类）做流量，治愈向（选题 1 类）黏人设，双线配比 6:4
3. **Seedance 2.5 实测待验证项**：30s 直出成片率、角色一致性对比 2.0、参考素材上限实用性——本周产出工具评测笔记反哺工作流
4. **世界杯余热二创红利期**：仅剩约 1 周情绪窗口，选题 1 须本周内出片，过期即降温
